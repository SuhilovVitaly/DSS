# Нативная проверка EP-0013

Из корня DSS после сборки решения:

```powershell
dotnet run --project tools/DeepSpaceSaga.Performance --no-build -- D:/DeepSpaceSaga/DSS D:/DeepSpaceSaga/artifacts/validation/ep0013/native-run/report.json --debug-window 1 ru
```

Использовать уникальный run-каталог. Повторить с `1.5 en`. Режим открывает реальное
Skia/OpenGL окно, передаёт managed key edges через production tracker/screen,
применяет реальные команды Engine и проверяет ширину/F12/Esc, mouse capture,
5,5км/с, W+D и подтверждённое удаление текущего tuning-файла. Временные settings
меняются только в build output и восстанавливаются. Tuning/metrics и GPU PNG
остаются в run-каталоге; внутренний timeout60с. Внешний тестовый процесс следует
ограничивать300000мс. Режим не является hardware input injection, проверкой звука
или человеческой визуальной/продуктовой приёмкой.

Gameplay контракты: [панель](../../DB/Documentation/04-Engineering/DebugTuningPanel.md)
и [ручные оси](../../DB/Documentation/04-Engineering/ManualManeuver.md).
