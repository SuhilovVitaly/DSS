# Палуба «Тетрарха»

Самостоятельное настольное приложение для Windows. Запустите `DeepSpaceSaga.TetrarchDeck.exe` из каталога поставки. Требуется .NET 8 Desktop Runtime. В Visual Studio проект находится в папке решения `tools`.

## Управление

- Щёлкните по человеку на палубе, затем по свободному участку пола. Щелчок по имени также выбирает человека и приближает его отсек.
- Золотая линия показывает маршрут. Новая цель вступает в силу со следующего шага. Люди обходят стены, занятые клетки, чужие маршруты и оборудование.
- Колесо меняет масштаб вокруг курсора. Правая или средняя кнопка с перетаскиванием перемещает камеру. Кнопка «Весь корабль» возвращает обзор.
- Наведение на оборудование показывает его назначение. В меню «Сценарий» можно сменить корабельную конфигурацию. При загрузке люди случайно распределяются по отсекам.

## Как приложение связано с DSS

`ScenarioLoader.LoadFromFile` читает сценарии клиента и разрешает ссылки на стартовые манифесты. Приложение выбирает корабль игрока класса `ship.tetrarch`. Установленные модули, состав экипажа, портреты, груз, топливо, вместимость жилых блоков и приписку каждого действующего дрона оно получает из файлов игры. Начальная конфигурация — Demo, если этот сценарий доступен. Чтобы читать рабочие файлы игры напрямую, передайте `--content D:\DeepSpaceSaga\DSS\src\DeepSpaceSaga.Client`. Перемещения людей действуют в текущем сеансе просмотра.

Каждый модуль занимает квадрат из 12×12 тайлов. Расположение модулей следует координатам корпуса из сценария. Структурные ячейки многоклеточного ангара делят между собой эти 12×12 тайлов. Свободные полосы корпуса содержат переходы и закрытые панели. В жилом блоке у каждой каюты есть дверь, койка и рабочее место. Длина дрона составляет пять ростов человека, высота — полтора. Занятые оборудованием клетки участвуют в поиске пути.

Во всех отсеках и переходах лежит одна матовая серая плитка с тонким швом. Подсветка под курсором и линия приказа отмечают цель и маршрут.

Ходьба использует объёмную модель с сорока фазами движения суставов. Приложение интерполирует позу по пройденному расстоянию и разворачивает модель в сторону движения. В покое персонаж слегка переносит вес и дышит, удерживая обе стопы на палубе. Частота и фаза покачивания различаются у членов экипажа.

В `Art/crew-motion.bin` хранятся геометрия формы, поза покоя и цикл ходьбы. Исходный корпус и движение адаптированы из Cesium Man © 2017 Cesium. Авторство и условия использования указаны в [уведомлении](Art/NOTICE-Cesium.txt). [Скрипт подготовки](ArtSource/bake_crew.py) принимает исходный GLB и путь к выходному файлу. Портреты в `Art/heads.png` соединяются с шеей движущейся модели. Если в старом сценарии опущены поля внешности, приложение ищет тот же ID персонажа в других конфигурациях.

Для спрайтов `Art/drone-utility.png`, `Art/desk.png` и `Art/heads.png` использован встроенный ImageGen. Художественные задания — бескрылый блочный орбитальный дрон с утопленными соплами и керамической обшивкой, компактный рабочий стол каюты с тёплой подсветкой и зелёным экраном, шесть голов по игровым портретам спереди и сзади в три четверти. Файлы PNG входят в поставку.

## Сборка и проверка

Из корня репозитория DSS в PowerShell:

```powershell
$run = Join-Path 'D:/DeepSpaceSaga/artifacts/validation/tetrarch-deck' (Get-Date -Format 'yyyyMMdd-HHmmss-fff')
New-Item -ItemType Directory -Path $run | Out-Null
dotnet publish tools/DeepSpaceSaga.TetrarchDeck -c Release -m:1 --artifacts-path "$run/build" -o "$run/TetrarchDeck"
dotnet "$run/TetrarchDeck/DeepSpaceSaga.TetrarchDeck.dll" --verify "$run/Deck.png"
```

Проверка сверяет состав и размеры модулей, размещение дронов и доступность всех свободных клеток. Для каждого сценария она строит маршруты при восьми разных расстановках экипажа. Оконный контрол получает сообщения мыши для выбора, перемещения и приближения. Проверка сохраняет общий вид и увеличенный кадр кают. Дополнительный параметр `--frames "$run/frames"` записывает ходьбу с поворотом и три секунды покоя после прибытия в PNG с частотой 30 кадров в секунду.

При обычном запуске окно располагается на меньшем по площади дисплее. Для оконной проверки можно передать `--monitor <индекс>` из `Screen.AllScreens` и выставить `DSS_VALIDATION_SMALL_MONITOR=1`. Приложение проверяет индекс и площадь дисплея до показа окна.
