# Симулятор движения дронов

Откройте `index.html` в современном браузере двойным щелчком. Установка,
доступ в интернет и сервер не нужны.

## Как играть

1. Выберите свой дрон на поле или карточкой снизу.
   Наведение в любую часть гекса со своим дроном только подсвечивает его;
   предпросмотр траектории другого дрона в этой клетке скрыт. Клик в любую часть
   такого гекса выбирает дрон, сохраняя прежние приказы. Весь гекс со своим дроном
   имеет приоритет над стрелкой или конечной клеткой под ним.
2. Доступные конечные клетки слегка затемнены. Наведите мышь на клетку,
   чтобы увидеть предварительную траекторию и конечный курс.
   Щелчок выбирает план; повторный щелчок по клетке переключает возможные планы.
   При наведении в конечной клетке показаны стрелки всех доступных конечных курсов; можно нажать нужную стрелку. После выбора клетки курсы также доступны отдельными кнопками над основным действием. Можно выбрать полный план в правой панели. Линии идут по центрам гексов.
   Сохранённые траектории и конечные стрелки всех своих дронов остаются на поле,
   в том числе после ухода мыши и переключения на другой дрон. Выбранный дрон
   показан ярче. Предпросмотр не меняет сохранённый приказ до щелчка.
   Конечную клетку, занятую сейчас другим своим дроном, также можно выбрать
   через список планов справа, а затем указать конечный курс кнопкой.
3. Для ручного ввода нажмите «Сначала», затем добавляйте шаги и повороты.
   Обязательный первый шаг уже добавлен. «Отменить» убирает последнее действие.
4. Нажмите «Выполнить движение». Дроны обеих сторон исполняют действия одновременно.
5. В фазе стрельбы нажмите «Завершить стрельбу», чтобы начать следующий раунд.

По умолчанию в начале каждого раунда всем четырём дронам игрока назначен
и показан полный прямой ход по текущему курсу: 3 шага тяжёлым, 4 лёгким.
Tab / Shift+Tab переключает свой дрон; Enter выполняет основное действие,
когда фокус не находится на кнопке или другом элементе ввода.
«Новый бой» возвращает начальную расстановку.

## Правила этого прототипа

- Сторона игрока и ИИ: по 2 тяжёлых дрона с бюджетом 3 и 2 лёгких с бюджетом 4.
- Каждый шаг вперёд на один гекс и каждый поворот на 60° стоят 1 единицу.
- Первый шаг вперёд обязателен в каждом ходу. Два поворота подряд запрещены.
- План расходует весь бюджет: у тяжёлого 5 вариантов, у лёгкого 11.
- Курс по часовой стрелке: 30°, 90°, 150°, 210°, 270°, 330°; 90° — вправо.
- Исполнение состоит из четырёх синхронных подшагов. На четвёртом тяжёлые ждут.
- Перед каждым подшагом рассчитываются предполагаемые конечные клетки всех дронов.
  Если несколько дронов претендуют на одну клетку, их перемещения отменяются:
  они остаются в исходных клетках, без захода в общую клетку и без отскока.
- Если из-за отмены клетка другого дрона не освобождается, вход в неё также
  отменяется. Проверка повторяется до согласования всех перемещений, до анимации.
- Поворот на месте и ожидание тяжёлого дрона сохраняются; входящий в его клетку
  дрон остаётся на месте. В освободившуюся клетку движущегося дрона входить можно.
- Отменённый шаг расходует действие. Следующие действия плана выполняются
  из фактической позиции; курс не меняется из-за блокировки движения.
- Обмен клетками и пересечение рёбер без совпадения конечной клетки подшага
  столкновением не считаются.
- Поле продолжается за видимый край, поэтому нет отдельного правила столкновения
  с границей. Масштаб и положение камеры сохраняются между фазами и раундами.
  «Всё поле» вручную подгоняет вид по дронам и доступным планам; «Новый бой»
  возвращает начальный вид. Во время исполнения движения подгонка недоступна.
- ИИ фиксирует полный план в начале раунда, исходя из текущих видимых позиций,
  и стремится сблизиться с противником. Приказы игрока он не читает.
- Стрельба — явная заглушка. Брони, пушек, носителей, торпед, урона и победы нет.

Это самостоятельная программа для проверки обсуждаемой механики. Совпадающего
канонического задания Board для её интеграции в DSS при создании не найдено;
интеграция с основным движком не входит в данный прототип.

## Файлы и проверка

`logic.js` — чистые правила, `app.js` — состояние фаз и интерфейс,
`index.html` / `style.css` — экран. Все зависимости локальные.

При наличии Node.js: `node --test logic.test.cjs`.
Тесты проверяют наборы планов, направления, промежуточные столкновения,
ожидающие и поворачивающиеся дроны, тройные столкновения и 100 раундов симуляции.
