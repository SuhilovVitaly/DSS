# W1: цельные лица

Набор W1 сохранён; по умолчанию `TempCharacterImage` теперь открывает [W4](PortraitGeneratorW4.md). W1 можно открыть явной передачей пути в `TempCharacterImageScreen`. Клик по портрету выбирает новое сочетание. Стрелками можно менять овал, цельное лицо, причёску и костюм. Сохранения W1 используют `temp-character-w1.json`.

Набор расположен в `src/DeepSpaceSaga.Client/Images/Persons/W1`:

| Папка | Содержимое |
|---|---|
| `Ovals` | 3 овала с подбородком, ушами и шеей, общий оттенок кожи |
| `Faces` | 10 цельных лиц: глаза, брови, нос и рот в одном прозрачном PNG |
| `Hair` | 10 прежних причёсок; в копиях убраны остатки кожи старого лица |
| `Clothes` | 3 прежних костюма с общей посадкой воротника |
| `Sources` | 13 исходных изображений, созданных без референсов |
| `Generated` | Проверочные таблицы сочетаний и превью окна |

Рабочие слои — прозрачные PNG 1024×1024. Порядок наложения: овал → цельное лицо → костюм → волосы. Доступно 900 сочетаний. Черты внутри одного лица не перемещаются и не смешиваются отдельно. Лицо целиком получает одно равномерное преобразование; края кожи согласованы с общей областью трёх основ. Нижняя шея у всех основ одинакова и перекрывается воротником.

Изображения сгенерированы встроенным `image_gen` без приложенных референсов. Полные запросы сохранены в `tools/DeepSpaceSaga.PortraitAssets/w1-prompts.json`. Техническая подготовка слоёв выполняется в `WholeFaceAssets.cs`.

Пересобрать слои из сохранённых исходников и таблицы проверки:

```powershell
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- w1 src/DeepSpaceSaga.Client/Images/Persons/W1
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- preview src/DeepSpaceSaga.Client/Images/Persons/W1
```

Игра загружает PNG и JSON из W1 рядом с исполняемым файлом; `Sources` и `Generated` в поставку не включаются. Авторская утилита не нужна для запуска игры. Старый набор `W/PortraitGenerator`, его исходники и поддержка прежних версий сохранены.
