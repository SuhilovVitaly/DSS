# W4: цельный портрет и костюм

По умолчанию `TempCharacterImage` открывает W4. Кнопки «Женщины» и «Мужчины» переключают W4 и [мужской набор M4](PortraitGeneratorM4.md). В окне два выбора: персонаж и костюм. Справа — карточки персонажей со страницами по три карточки; выбор карточки сохраняет текущий костюм. Клик по большому портрету создаёт другое сочетание. Сохранения W4 используют отдельный `temp-character-w4.json`.

Все PNG непосредственно в `W4/Portraits` автоматически подключаются при открытии окна, без добавления записей в `parts.json`. Расширение нечувствительно к регистру. Вложенные папки со служебными файлами не сканируются. Для портретов из каталога сохраняются прежние ID и имена; новые получают постоянный ID по имени файла. Удалённые портреты исключаются из выбора, поэтому сохранение с таким портретом больше не загрузится.

После добавления PNG в исходники соберите проект и перезапустите игру: сборка копирует их в `Images/Persons/W4/Portraits` рядом с исполняемым файлом. Если PNG добавлен прямо в папку запущенной игры, достаточно закрыть и снова открыть окно генерации. Портреты должны соответствовать W4: прозрачный PNG 1024×1024, голова с волосами и шеей, рассчитанная на общие костюмы.

Файлы: `src/DeepSpaceSaga.Client/Images/Persons/W4`.

- `Portraits` — прозрачные PNG: голова, все черты лица, причёска и собственная шея нарисованы вместе. Каждое изображение остаётся цельным.
- `Clothes` — три неизменённые копии совместимых костюмов W2.
- `Portraits/character-generator` — общий скилл генерации женских и мужских портретов. Временные примеры сборки создаются вне проекта и удаляются после проверки; Sources и Generated не создаются.

Рабочие PNG имеют размер 1024×1024. Порядок сборки: портрет → костюм. Подготовка ограничена очисткой прозрачного края и равномерным масштабированием/смещением целого изображения к воротнику. Отдельных овалов, лиц, подбородков, волос и шей в W4 нет.

Новые изображения создаются встроенным `image_gen` через [Character Generator](../../src/DeepSpaceSaga.Client/Images/Persons/W4/Portraits/character-generator/SKILL.md). Для женщин `scripts/prepare.ps1` использует W4 по умолчанию; для мужчин укажите `-Gender male`. Старый инструмент `UnifiedPortraitAssets w4` рассчитан на историческую раскладку с меньшей головой и не используется для новых персонажей.

Игра загружает только рабочие PNG и JSON из W4 рядом с исполняемым файлом. `Sources` и `Generated` не входят в сборку и публикацию.
