# Портреты в диалогах

Общий DialogueScreen, включая стыковку, использует DialoguePortraitComposer и тот же PortraitRenderer, что и TempCharacterImage. Голова с волосами и шеей и костюм из W4/M4 складываются на полном квадратном холсте и уменьшаются до 300×300. Старые координаты тела и обрезка маленькой головы здесь больше не используются.

Капитан по умолчанию — старший мужчина `M4/Portraits/CHR-20260915-105947-6DC202.png`. Костюм выбирается детерминированно по идентификатору персонажа. Смена реплики и повторное открытие окна не меняют внешность. При смене говорящего обновляются роль, лицо и имя.

При запуске через Settings.json, выбранный сценарий или сохранение EngineContentLoader считывает все PNG непосредственно из `Images/Persons/W4/Portraits` относительно Settings.json, без вложенных папок. Регистр расширения не важен. При отсутствии заданного portraitImage движок выбирает лицо по masterSeed, ID станции и ID члена экипажа. Готовый относительный путь записывается в сохранение: добавление новых PNG не меняет лица уже сохранённых персонажей. Каталог читается один раз при запуске сессии.

В Default, Default_500, Docked и Undocked удалены прежние заданные женские изображения. Явно указанные портреты капитана в Docked и Undocked заменены на M4; остальные сценарии получают того же капитана по умолчанию.

Старые сохранения с путями Persons/W и Persons/M отображаются через новые наборы: мужской портрет заменяется на старшего мужчину, женский выбирается стабильно по ключу персонажа. Исходные сохранённые данные не переписываются. Явные ссылки на конкретные PNG W4/M4 сохраняют выбранную личность. Если такой файл удалён, загрузчик изображения возвращает пустой результат без падения диалога.

Новые исходные PNG попадают в игру после сборки и перезапуска. Портреты собираются в памяти при смене персонажа; дополнительные Generated/Sources и готовые диалоговые PNG на диске не создаются.
