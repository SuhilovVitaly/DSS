# Fuel двигателя

Статус: решение первого релиза принято, требует реализации.

Основные источники: `Documentation/01-Requirements/EngineRequirements.md`, `TetrarchClass.md`, `CommandPanels.md`.

## Решение первого релиза

- `Fuel` является отдельным ресурсом/товаром для двигателя.
- Единица измерения `Fuel` в первом релизе: kg.
- `Fuel` хранится только во внутренних баках двигателя.
- `Fuel` нельзя складировать в cargo/container module.
- `Fuel` не занимает cargo capacity.
- Грузовой отсек не используется для хранения топлива.
- Вместимость топлива задается параметром двигателя, например существующим `fuelCapacityKg` у `module.engine.basic`.
- В стартовой комплектации `module.engine.basic` имеет `fuelCapacityKg = 1000`; сценарии первого релиза задают `fuelAmountKg = 750` (75% бака).
- В Tetrarch Class двигатель находится в клетке `(4,5)` и использует `module.engine.basic`.
- `Energy Cells` не являются топливом двигателя; они остаются cargo item для реактора/генератора и электросистемы.
- В базовом MVP команды двигателя/навигации не расходуют `Fuel`.
- В новой экономике межстанционных рейсов планируется отдельный `route fuel cost`: расход топлива и его стоимость входят в расчёт чистой торговой прибыли, но не меняют текущую семантику отдельных команд двигателя до отдельной реализации.

## Цель

Корабль игрока должен иметь ресурс топлива и интерфейс заправки на станциях. До реализации route fuel cost расход отдельными командами остаётся отключённым.

## Требования первого релиза

- Игрок должен видеть текущий запас `Fuel` в kg и максимальную вместимость баков двигателя в kg.
- Если на корабле несколько двигателей, каждый двигатель хранит собственный запас `Fuel`; общее поведение нескольких двигателей требует отдельного уточнения перед реализацией.
- Команды двигателя/навигации первого релиза не блокируются из-за недостатка `Fuel`.
- Пополнение `Fuel` доступно только в пристыкованном состоянии на станции или через утвержденный станционный сервис.
- Пополнение `Fuel` заполняет бак двигателя, а не добавляет item в cargo.
- Сохранение/загрузка должны сохранять текущий запас `Fuel` в баках двигателя.

## UI первого релиза

- `GameSessionScreen` должен показывать текущий запас `Fuel` игрокского двигателя.
- В пристыкованном состоянии игрок должен иметь действие заправки.
- UI не должен показывать fuel cost для команд, пока расход топлива командами отключен. Прогноз чистой прибыли торгового рейса может учитывать отдельный route fuel cost только после его authoritative включения.

## За рамками базового MVP двигателя

- Fuel cost для команд двигателя/навигации.
- Полный route fuel cost торгового рейса до отдельной реализации экономического цикла.
- Блокировка команд из-за недостатка `Fuel`.
