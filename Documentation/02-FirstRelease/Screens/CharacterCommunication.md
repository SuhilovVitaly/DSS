# Character Communication

Статус: экран не реализован.

## Назначение

Окно общения с персонажами. Используется, когда игрок выбирает, с кем говорить, или когда разговор привязан к кораблю/экипажу.

## Функциональность первого релиза

- Показывает доступных персонажей.
- Для корабля показывает главного героя и будущих членов экипажа/пассажиров.
- Позволяет открыть линейный `Dialog` с выбранным персонажем.
- Из `Ship` используется для общения с экипажем.
- Из `Session` может использоваться как быстрый доступ к коммуникациям.

## Связанные механики

- `CrewAndHabitation`.
- `CrewDialogues`.
- `PassengerContracts`.
