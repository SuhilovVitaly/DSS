# Поражение

Показывает терминальный исход из подтверждённого состояния. Переход должен работать и поверх открытых модалей. Продолжение/Load создаёт новую сессию; stale Save callbacks старой сессии не должны менять слот.

См. [каталог экранов](ScreenCatalog.md) и [основные требования](../../01-Requirements/EngineRequirements.md).
