# Диалог

Общий DialogueScreen показывает говорящего, роль, текст и варианты ответа. Engine владеет dialogue state, условиями и эффектами. Смена реплики не должна менять личность персонажа; портрет собирается из W4/M4 в памяти.

См. [каталог экранов](ScreenCatalog.md) и [основные требования](../../01-Requirements/EngineRequirements.md).

Источники: [DialogueScreen.cs](../../../src/DeepSpaceSaga.Client/UI/Screens/Dialogue/DialogueScreen.cs).
