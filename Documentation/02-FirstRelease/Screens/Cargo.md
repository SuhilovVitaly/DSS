# Cargo

Статус: экран не реализован.

## Назначение

Окно грузового отсека корабля. Открывается из `Session`.

## Функциональность первого релиза

- Показывает cargo-товары в грузовом отсеке.
- Показывает занятую и доступную вместимость.
- Показывает `Energy Cells` как обычный грузовой товар.
- Не показывает `Fuel` как груз в контейнере, потому что `Fuel` хранится только в баках двигателя.
- Может показывать `Fuel` отдельной строкой состояния двигателя, если это нужно для удобства игрока.

## Связанные механики

- `CargoHold`.
- `Fuel`.
- `ElectricityAndEnergyCells`.
- `Trading`.
