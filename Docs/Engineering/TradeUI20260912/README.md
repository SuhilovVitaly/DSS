# Новое окно торговли

Реализован предложенный интерфейс с дополнительным условием пользователя: общий верхний тулбар станции сохранён. `StationToolbar.cs`, его размеры, отрисовка, навигация, показатели и подсказки не изменены. Размер окна остался 1600×800. Новый интерфейс рисуется только ниже полосы тулбара, с отдельным clipping.

## Поведение

- Один каталог ресурсов и товаров: поиск по названию/ID, фильтры категории и наличия в выбранном трюме, сортировка четырёх колонок, прокрутка колёсиком и перетаскиванием полосы. Пустой рынок модулей удалён.
- Постоянная панель выбранного товара: покупка/продажа, конкретный контейнер, ввод целого количества с клавиатуры, быстрые количества, ползунок и максимум. Максимум учитывает стоимость, остаток станции, массу товара и свободное место. Продажа учитывает собственный груз и доступный лимит закупки станции, не раскрывая баланс станции.
- До подтверждения видны итоговая стоимость, баланс, количество товара и загрузка трюма после сделки. Ошибочные и слишком большие числа не допускают отправку.
- Заправка отделена от грузового каталога: выбор конкретного бака, количество добавляемого топлива и целевые уровни 50%, 75%, 100%, ограниченные доступным топливом и деньгами. Топливо направляется в бак, груз не изменяется.
- Во время ожидающей подтверждения операции повторная отправка блокируется. Выбранный товар и количество сохраняются после ответа. Ошибки и фактически исполненные количества частичной продажи отражаются в статусе и истории.
- История последних 50 операций относится к текущей игровой сессии и сохраняется при закрытии/повторном открытии торговли. Это не новая очередь заказов и не изменение формата сохранённой истории игры.
- Enter в поле сначала заканчивает ввод; отдельное нажатие вне поля отправляет сделку. Повтор удерживаемой клавиши и повторные клики во время ожидания не отправляют вторую команду. Escape сначала закрывает редактирование/список/историю, затем окно. Тулбарные выход и возврат на станцию работают как раньше.

## Код и данные

Вместо прежнего большого файла выделены расчёт предложения и состояние каталога (`TradeModel`), работа с вводом (`TradeScreen`), отрисовка (`TradeScreen.Render`, `TradePainter`), существующая интеграция тулбара (`TradeScreen.Toolbar`), имена и изображения товаров (`TradeItemPresentation`). Каталог перестраивается при изменении снимка или фильтра, изображения используют общий кэш UI.

В Contracts добавлены необязательные завершающие поля `StationInventoryItemSnapshot.UnitMassKg` и `InstalledModuleSnapshot.CargoCapacityKg`; Engine передаёт реальные значения из каталога типов. Новых торговых команд и изменения правил экономики нет. Точный результат по-прежнему определяет Engine. Добавлены русские и английские строки только для нового содержимого окна.
