# Конструктор женских портретов

Первая рабочая версия из этапа MVP ТЗ: взрослые женщины, человек, иллюстративный аниме-стиль с мягким светом. Ориентир — все шесть исходников `Images/Persons/W`; точное совпадение с их фотореализмом не заявляется. Оригиналы не изменены.

## В игре

На игровом экране, в нижней панели рядом с F и S, находится **TempCharacterImage**. Кнопка открывает модальное окно и создаёт случайного персонажа. Левый клик по портрету или пробел создаёт следующего. Escape, «Закрыть» или клик вне окна закрывает конструктор. Используется штатная пауза/возобновление модальных экранов.

- Нажатие на категорию переключает совместимые варианты.
- Замок сохраняет деталь или цвет при случайной генерации.
- Кнопки внизу отдельно меняют лицо, причёску, цвета или аксессуары.
- Seed + «Создать» восстанавливает исходную генерацию, игнорируя замки. После ручных изменений точным источником восстановления является JSON, а не только seed.
- Поддержаны 30 действий отмены/повтора.
- «Сохранить JSON» и «Загрузить JSON» используют `%LOCALAPPDATA%/DeepSpaceSaga/PortraitPresets/temp-character.json`. Сохранение заменяет предыдущий временный preset.
- Справа можно переключать все доступные исходники и сравнивать их с результатом в режиме 50/50.

## Графика и упаковка

По правилу `AGENTS.md` графика находится **рядом с репозиторием**, в `D:/DeepSpaceSaga/DSS-Images/temp/PortraitGenerator`:

| Папка / файл | Содержимое |
|---|---|
| `Sources` | Три оригинальных атласа, созданных встроенным imagegen |
| `Parts` | 44 прозрачных компонента PNG RGBA, каждый 512×512 |
| `Masks` | Четыре маски радужек для независимого окрашивания |
| `portrait-style.json` | Размеры, нормализованные опорные точки, порядок слоёв, палитры, лимит кеша |
| `parts.json` | Неизменяемые ID, пути, каналы цвета, веса и правила совместимости |
| `reference-analysis.json` | Автоматическая инвентаризация всей папки W, размеры, альфа, SHA256, описание адаптации |
| `Golden` | Шесть проверенных изображений; `v1` сохраняет JSON прежних персонажей для проверки совместимости |
| `Generated` | Примеры, JSON внешности, контактный лист и снимок окна |

В наборе 12 вариантов лица и по четыре варианта глаз, бровей, носа, рта, задних волос, передних волос, одежды и аксессуаров. Уши и шея пока входят в слой лица. Глазной слой содержит белки, радужки, зрачки и блики; маска позволяет перекрашивать только радужки. Отдельные цветовые PNG не создаются.

Восемь добавленных лиц имеют отдельные ID `female.face.005`–`female.face.012`: круглое, квадратное, сердцевидное, ромбовидное, вытянутое, грушевидное, с высокими скулами и с полными щеками. Различаются силуэт челюсти, объём щёк, скулы и ширина лба. Верх головы вписан в существующий контур причёсок, нижняя часть шеи плавно соединена с проверенным посадочным местом. `Generated/face-diversity.png` сравнивает новые формы при одинаковых волосах, глазах, цветах и одежде; в редакторе отображаются названия форм.

Шея продолжается под воротником до y=430; маска силуэта убирает только расширение исходного бюста у плеч. У каждого костюма свой вырез: задняя часть воротника пропускает шею, передняя кромка и нижняя одежда перекрывают её. Горизонтального обрезания шеи по верхнему краю воротника нет. `Generated/neck-collar-combinations.png` показывает все 48 сочетаний лиц и костюмов; отдельный тест проверяет кожу внутри выреза и отсутствие прозрачных щелей по всему стыку.

Для естественной длины шеи весь слой костюма вместе с маской выреза поднят на 42 пикселя. Подбородок остаётся около y=338, передние края воротников располагаются на y=372–381: открытая часть шеи занимает примерно 34–43 пикселя. Плечи поднимаются вместе с воротником, пропорции самой одежды и лица сохраняются. Отдельный регрессионный тест ограничивает расстояние от подбородка до передней кромки для всех четырёх костюмов.

`DeepSpaceSaga.Client.csproj` копирует рабочую библиотеку в `Images/PortraitGenerator` при сборке и публикации. Исходные атласы, примеры и эталоны в клиент не попадают. Тестовый проект получает `Golden` отдельно. При переносе репозитория нужно также переносить соседний каталог библиотеки; это намеренное следствие правила хранения изображений проекта. Без каталога сборка выдаёт понятную ошибку.

## Архитектура

Код находится в `src/DeepSpaceSaga.Client/Portraits`. Он не обращается к игровому движку или экрану. `PortraitModels.cs` содержит модель внешности и детерминированный генератор без графических зависимостей; SkiaSharp используется загрузчиком и рендерером.

```csharp
var assets = new PortraitAssetRepository(packDirectory);
var generator = new PortraitGenerator(assets);
CharacterAppearance appearance = generator.Generate(7642381);
string json = AppearanceSerializer.Serialize(appearance);
CharacterAppearance restored = AppearanceSerializer.Deserialize(json);
using var renderer = new PortraitRenderer(assets);
SKImage image = renderer.Render(restored, 256);
```

`SKImage` принадлежит рендереру: вызывающая сторона не освобождает его и не хранит после вытеснения из кеша/освобождения рендерера. Экран удерживает только последний полученный портрет. Все вызовы одного рендерера выполняются на одном потоке.

Порядок категорий загружается из профиля. Положение компонентов запечено в единый прозрачный холст по опорным точкам; рендерер не содержит координат лица. Окрашивание умножает RGB на отношение выбранного и исходного цветов, сохраняя относительную яркость теней и бликов. Для радужек применяется маска.

Генератор использует явный 32-битный PRNG с фиксированной арифметикой, сортирует ID перед взвешенным выбором и проверяет окончательную комбинацию, включая зависимости на последующие слои. Поддержаны requires/excludes для тегов и ID. В текущем наборе гарнитура исключает длинные задние волосы, скрывающие крепление. Число попыток ограничено, невозможные ограничения возвращают ошибку.

Внешность хранит `version`, `libraryVersion`, seed, ID компонентов и цвета. Реализована миграция раннего формата v0 → v1; неизвестные будущие версии отвергаются. При изменении состава/весов набора нужно поднять `libraryVersion`, сохранить старый набор для старых NPC либо добавить явную миграцию. Выпущенные ID нельзя назначать другой графике.

Текущая библиотека имеет версию 2 и поддерживает версии 1 и 2. Старые ID и веса сохранены; новые компоненты помечены `introducedInVersion: 2`. `generator.Generate(seed, 1)` точно воспроизводит прежнюю генерацию, а `Generate(seed)` использует актуальную библиотеку. Старые JSON загружаются без потери внешности. Ручное переключение на новое лицо переводит описание на версию 2.

Визуальное состояние (`CharacterVisualState`) отделено от внешности. Метаданные допускают текстуры выражений; текущий художественный набор содержит только нейтральные варианты, остальные выражения используют исходную текстуру. Кеш учитывает внешность, состояние и размер, хранит 32 изображения по LRU и освобождает вытесненные изображения. Экран рисует готовый снимок без повторной композиции каждый кадр.

## Создание и проверка набора

Инструмент `tools/DeepSpaceSaga.PortraitAssets` нормализует атласы в прозрачные слои, формирует метаданные, анализирует всю директорию референсов и проверяет библиотеку. Прямоугольники исходного атласа в инструменте — ручная калибровка производства графики, а не параметры runtime.

Промпты встроенного imagegen сохранены в `tools/DeepSpaceSaga.PortraitAssets/generation-prompts.json` и `face-diversity-prompts.json` в той же папке. AI использовался только при подготовке исходных атласов; генератор в игре работает полностью локально. Новый атлас пришёл с нейтральной клетчатой подложкой: импортёр выделяет непрерывный тёплый силуэт кожи по строкам, удаляет подложку, нормализует опорные точки и сохраняет настоящие PNG RGBA с прозрачным фоном.

Из каталога DSS:

```powershell
# Валидация метаданных и PNG без перегенерации
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- validate ../DSS-Images/temp/PortraitGenerator

# Примеры для шести фиксированных seed + 10 000 композиций 128×128
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- bake ../DSS-Images/temp/PortraitGenerator

# Изображение реального игрового окна для визуальной проверки
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- preview ../DSS-Images/temp/PortraitGenerator

# Восстановление деталей из Sources (заменяет производные детали и metadata)
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -p:SkipPortraitPackCheck=true -- build ../DSS-Images/temp/PortraitGenerator src/DeepSpaceSaga.Client/Images/Persons/W

dotnet test DeepSpaceSaga.sln
```

Golden не перезаписывается командой bake. После намеренного изменения художественного набора сначала следует проверить контактный лист, а затем отдельно обновить эталоны. Полная валидация текстур и метаданных выполняется инструментом, при загрузке окна и тестами; обычная сборка проверяет наличие каталога и профиля.

Проверки: воспроизводимость, сериализация/миграция, совместимость, веса, уникальность ID, безопасность путей, сохранение белков при окрашивании, ключ и LRU кеша, шесть визуальных эталонов, клики/масштабирование/блокировки/отмена/JSON в редакторе. Отдельный bake проверяет 10 000 фактических композиций: размер, альфа-формат, наличие файлов, ограничения и отсутствие исключений. На рабочей машине этот прогон занял 44,1 секунды; это измерение полного pipeline при 128×128, не GPU-бенчмарк.

## Расширение

Для новой причёски достаточно добавить согласованный PNG 512×512 и запись с новым ID в `parts.json`. Цвета и порядок слоёв расширяются через профиль. Автоматическая декомпозиция готовых исходных портретов не выполняется.

Следующие этапы исходного ТЗ — художественные выражения, возраста, расы, шрамы/татуировки, архетипы, асимметрия, временные повреждения, редактор выделения компонентов и привязка внешности к сохранениям реальных NPC — в эту временную женскую MVP-систему не входят. Модель внешности уже сериализуется независимо от UI, поэтому её можно затем встроить в данные персонажа.
