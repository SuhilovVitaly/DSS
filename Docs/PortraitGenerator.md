# Женские портреты в анфас

Библиотека версии 10 содержит 16 основ лица, 11 вариантов бровей, 20 пар глаз, по 13 вариантов губ и носов, десять причёсок, по три подбородка и костюма. Всего 53 539 200 сочетаний. Десять дополнительных основ созданы по выбранным портретам из `DSS-Images/Persons`; их подготовленные версии в анфас также разобраны на 40 самостоятельных деталей. Прежние варианты сохранены.

## Окно

Кнопка **TempCharacterImage** на игровом экране открывает конструктор. Стрелки возле детали переключают только её; кнопка с названием показывает отдельный слой. Клик по портрету, пробел или «Случайный портрет» выбирают новое сочетание. Справа можно перелистывать исходные референсы. Escape и «Закрыть» закрывают окно. Клики до первого кадра и за пределами окна игнорируются, чтобы повторное нажатие на кнопку открытия не закрыло конструктор сразу.

При открытии проверяются каталог и наличие файлов; декодируются только выбранные слои портрета. Полная проверка пикселей всех PNG выполняется утилитой `validate` и тестами. В `Interface.log` записываются фактический путь набора и время открытия.

«Показать пропорции» включает направляющие. JSON сохраняется в `%LOCALAPPDATA%/DeepSpaceSaga/PortraitPresets/temp-character.json`. ID деталей и seed воспроизводимы. Поддерживаются версии 4–10: прежние портреты v4–v6 восстанавливаются без волос, v7 сохраняет прежнюю основу, v8 — свои шесть лиц, v9 — прежние детали на 16 лицах. Удалённые версии 1–3 отвергаются с сообщением, текущая внешность при ошибке сохраняется. «Глаза» переключает 20 вариантов, «Брови» — 11, «Нос» и «Губы» — по 13, «Причёска» — 10, «Овал» — 16, в обоих направлениях.

## Совмещение головы и костюмов

Дополнительные основы имеют собственную полноту щёк, скулы, линию челюсти и брови. Для каждой подготовлены три согласованных подбородка, три носа и три рта, а также исходная пара глаз. `FaceTextures` выбирает соответствующую текстуру по ID основы, сохраняя выбранные ID деталей при переключении лица. Для десяти новых основ подготовлены также 90 адаптированных слоёв остальных глаз: пара целиком сдвинута к измеренным центрам зрачков, окружающая кожа согласована по цвету. Форма и расстояние между глазами не растягиваются. Десять причёсок остаются общими. Изменений геометрии во время игры нет.

В v10 детали извлекаются из `Sources/faces/face-07-01.png` … `face-16-01.png`: это уже подготовленные версии десяти оригиналов в анфас и высоком разрешении, а не прямые вырезки из маленьких повёрнутых оригиналов. Новые ID: глаза 011–020, брови 002–011, носы и рты 004–013. Каждая из 40 деталей имеет 16 вариантов посадки, всего 640 PNG. Регистрация выполняется переносом без растяжения; цвет окружающей кожи согласуется по краю маски, края растушёваны. Глаза и брови переносятся парами. Исходники не перезаписываются, повторная команда начинает с тех же исходных пикселей. Новые запросы imagegen для выделения деталей не требуются.

Все рабочие PNG имеют размер 1024×1024 и альфа-канал. Исходная голова целиком равномерно помещается в прямоугольник `(176,12)–(848,684)`; регистрация дополнительных глаз выполняется заранее при подготовке PNG. Нижняя часть лица выделена в самостоятельный слой подбородка. Каждый вариант плавно переходит в одну и ту же нижнюю шею; у переднего края воротника её пиксели совпадают точно.

Три костюма созданы редактированием одного костюма с сохранением посадки. При извлечении используется единый контур внутреннего отверстия. Слой одежды накрывает нижнюю шею; сгенерированные вместе с одеждой лица и кожа в костюмный слой не попадают. Длина открытой шеи остаётся короткой и естественной.

Порядок сборки: подбородок с шеей → верхняя основа лица → костюм → брови → глаза → нос → губы → волосы. Причёска — один независимый слой `Hair`, обязательный начиная с v7. Он включает верхнюю часть волос и боковые пряди; лицо и центральный воротник вырезаны из слоя. Длинные волосы лежат поверх плеч. Ручные контуры выделения измерены на исходниках 1254×1254, фон удаляется цветовой маской, у корней используется мягкий переход. При смене причёски исходная геометрия головы и других деталей не меняется.

## Воспроизведение и проверка

Из каталога DSS:

```powershell
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- build src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- variants src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- eyes src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- hair src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- faces src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- features src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- validate src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- bake src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- preview src/DeepSpaceSaga.Client/Images/Persons/W/PortraitGenerator
dotnet test tests/DeepSpaceSaga.Client.Tests
```

`build` восстанавливает основу, костюмы, глаза, причёски и дополнительные лица при наличии исходников. `variants`, `eyes`, `hair` и `faces` также восстанавливают v10 после пересборки своих компонентов, если есть полный набор исходников лиц. При наличии только пяти прежних основ получается v8. `features` отдельно извлекает 40 дополнительных деталей и создаёт их обзоры. `fit-eyes` обновляет адаптированные слои прежних глаз десяти новых основ. Команды можно повторять без накопления смещений. `bake` проверяет сборку v4 против эталона и обновляет обзоры. Для первого восстановления без metadata используется `-p:SkipPortraitPackCheck=true`.

Тесты проверяют совместимость всех 129 600 сочетаний, 810 различных сборок прежнего лица и костюма, сохранение глаз и центрального воротника у всех 100 пар «глаза × волосы», 48 разных текстур подбородка с одинаковой нижней шеей, отсутствие отверстий у всех 144 сочетаний лица, подбородка и костюма, разницу ширины полного и худого лица, прежние версии, JSON, циклы выбора лиц, глаз и причёсок, случайную сборку, кеш и интерфейс при разных размерах окна. Отдельно проверяется побитовое сохранение шести лиц v8 при переходе на v9. Кеш декодированных слоёв ограничен 64 изображениями; повторное декодирование сохраняет результат. Матрицы новых основ также проверяются визуально.

Для v10 дополнительно проверяются все 640 сочетаний новой детали и лица: совместимость, разные результаты, неизменность пикселей за пределами центральной области лица, сохранение шеи и костюма, побитовое сохранение портретов v9. Все новые категории проверяются в циклах переключения интерфейса. Число 53 539 200 — произведение доступных вариантов, а не количество отрисованных тестовых портретов.

Клиент копирует рабочие PNG и JSON из своего каталога `Images/Persons/W/PortraitGenerator` в одноимённый каталог рядом с exe при сборке и публикации. Sources, Generated и Golden исключены из клиентского пакета; Golden отдельно копируется для тестов. Внешняя папка `DSS-Images/temp/PortraitGenerator` больше не используется. Игра загружает `parts.json` и `portrait-style.json` из локального набора и собирает готовые слои без запуска утилиты подготовки.
