# Мужские портреты M4

Откройте TempCharacterImage и нажмите «Мужчины» вверху окна. Справа выбирается персонаж; стрелки меняют голову или костюм, клик по большому портрету создаёт новое сочетание. Кнопка «Женщины» возвращает W4.

Файлы находятся в `src/DeepSpaceSaga.Client/Images/Persons/M4`:

- `Portraits` — готовые прозрачные PNG 1024×1024: лицо, уши, подбородок, волосы и собственная шея нарисованы вместе. Добавлены три взрослых мужчины: светловолосый, брюнет со щетиной и мужчина с сединой и короткой бородой.
- `Clothes` — три совместимых костюма, идентичные костюмам W4. Костюм накладывается поверх портрета.
- `portrait-style.json` — пол `male`, префикс ID `male.m4.portrait.file.`, размеры и порядок слоёв.
- `parts.json` — каталог костюмов. Каждый PNG непосредственно в Portraits обнаруживается автоматически при открытии окна, включая расширение `.PNG`. Вложенные служебные папки игнорируются.

Идентификатор нового портрета зависит от имени файла. Не переименовывайте используемые изображения: сохранения с прежним именем перестанут загружаться. Сохранения мужского и женского наборов разделены: `%LOCALAPPDATA%/DeepSpaceSaga/PortraitPresets/temp-character-m4.json` и `temp-character-w4.json`.

При добавлении PNG в исходники соберите проект и перезапустите игру; сборка и публикация копируют M4 вместе с W4. Если PNG добавлен в папку уже запущенной игры, переоткройте окно генерации.

Для новых изображений используйте общий [Character Generator](../src/DeepSpaceSaga.Client/Images/Persons/W4/Portraits/character-generator/SKILL.md) с описанием мужчины. Скилл сохраняет мужчин в M4 и женщин в W4; `scripts/prepare.ps1 -Gender male` проверяет три воротника. Генерация встроенным image_gen, цельный анфас, реалистичная кожа, мягкий фронтальный свет, компактная причёска, шея с естественным сужением под челюстью. Подготовка сохраняет пропорции головы равномерным масштабированием всего изображения.

Sources и Generated не создаются. Временные примеры сборки удаляются после визуальной проверки. Проверки MalePortraitTests и UnifiedPortraitTests охватывают загрузку, автоподключение PNG, сочетания с воротниками, переключение пола и раздельные сохранения.
