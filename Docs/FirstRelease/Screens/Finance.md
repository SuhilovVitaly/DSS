# Finance

Статус: экран не реализован.

## Назначение

Окно финансовых сведений и станционных финансовых операций. Открывается из `Station`.

## Функциональность первого релиза

- Показывает баланс `Credits` игрока.
- Может показывать сводку цен станции без раскрытия скрытого баланса станции.
- Может показывать финансовый результат последних торговых операций.
- Не показывает точный запас `Credits` станции, потому что он скрыт от игрока.

## Связанные механики

- `Money`.
- `Trading`.
- `StationInventory`.
