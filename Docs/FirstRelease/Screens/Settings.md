# Settings

Статус: экран уже существует в коде.

Код: `src/DeepSpaceSaga.Client/UI/Screens/Settings/`.

## Назначение

Экран пользовательских настроек.

## Функциональность первого релиза

- Настройки должны оставаться клиентской функциональностью и не смешиваться с authoritative state движка.
- Изменение UI scale должно влиять только на UI-панели, но не на координаты карты, hit-testing объектов и симуляцию.
- Закрытие настроек должно возвращать игрока в предыдущий экран.

## Будущие кандидаты настроек

- UI scale.
- Громкость, если появится звук.
- Настройки отображения тактической карты, если они не влияют на правила игры.
