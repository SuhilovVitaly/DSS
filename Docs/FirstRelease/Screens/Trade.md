# Trade

Статус: реализована заглушка (открытие/закрытие/пауза, без данных механик) — по тому же паттерну, что `Station`/`Finance`/`Ship`.

Код: `src/DeepSpaceSaga.Client/UI/Screens/Trade/` (`TradeScreen.cs`, `TradeLayout.cs`).

## Назначение

Экран торговли открывается со станционного экрана, является modal screen и позволяет покупать, продавать и заправлять двигатель.

## Предварительные условия

- Корабль игрока пристыкован к станции.
- Игрок находится на экране станции или в станционном UI-flow.
- Станция имеет конечный склад товаров и запас `Credits`.
- Игрок имеет cargo state, `Fuel` state и баланс `Credits`.
- Пока экран торговли открыт, действует modal pause rule.

## Функциональность первого релиза

- Показывает баланс `Credits` игрока.
- Не показывает баланс `Credits` станции явно.
- Показывает товары станции и доступные количества.
- Показывает товары игрока и доступные количества.
- Позволяет покупать cargo-товары со станции.
- Позволяет продавать cargo-товары станции.
- Позволяет заправлять `Fuel` в бак двигателя.
- Блокирует покупку, если у игрока недостаточно `Credits`, cargo capacity или у станции недостаточно товара.
- Разрешает частичную продажу, если у станции недостаточно `Credits` на весь выбранный объем товара игрока.

## UI первого релиза

- Для каждого товара показываются название, итоговая цена станции, количество у станции, количество у игрока.
- Для `Fuel` показывается заправочное действие отдельно от cargo-товаров, потому что `Fuel` не хранится в контейнере.
- Если станция может купить только часть выбранного товара, UI должен дать игроку продать максимально возможное количество или вручную выбрать меньшее количество.

## Архитектурные требования

- Торговые операции являются authoritative действиями Engine.
- Client не должен самостоятельно изменять балансы, склад или cargo state без подтверждения Engine.
- Открытие экрана торговли должно приостанавливать authoritative simulation через существующий modal pause mechanism.

## Статус реализации (MVP)

Реализовано: открытие кнопкой `TRADE` на `StationScreen` (нажатие возвращает `ScreenEvent.OpenTrade`, `SkiaWindow` пушит `TradeScreen` поверх `StationScreen` — вложенный modal, как `GameMenu → Save/Load`), закрытие `×`/`Escape`/кликом по фону вне панели (возврат на `Station`), панель `1400×900`, modal pause через существующий `PushModalAsync`/`PopModalAsync`.

Не реализовано — экран показывает одну placeholder-строку "not available yet" вместо этого: баланс `Credits`, товары станции/игрока, покупка/продажа, заправка `Fuel`. Ничего из раздела «Функциональность первого релиза» выше фактически не работает.
