# Dialog

Статус: экран не реализован.

## Назначение

Универсальное модальное окно линейного диалога. Используется для коротких разговоров с экипажем, пассажирами и представителями станции, когда не нужен отдельный экран выбора персонажа.

## Функциональность первого релиза

- Показывает имя персонажа.
- Показывает текст текущей реплики.
- Позволяет перейти к следующей реплике.
- Позволяет закрыть завершенный диалог и вернуться в предыдущий экран.
- В первом релизе диалоги линейные, без ветвления.
