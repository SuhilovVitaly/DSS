# Station

Статус: реализована заглушка (открытие/закрытие/пауза, без данных механик) — по тому же паттерну, что `Finance`/`Ship`.

Код: `src/DeepSpaceSaga.Client/UI/Screens/Station/` (`StationScreen.cs`, `StationLayout.cs`).

## Назначение

Экран станции открывается, когда корабль игрока пристыкован к станции. Это основной hub для станционных действий и modal screen, который ставит симуляцию на паузу.

## Предварительные условия

- Игрок находится в игровой сессии.
- Корабль игрока пристыкован к станции после успешной команды `navigation.dock`.
- Engine подтверждает состояние стыковки и station id.
- Пока экран станции открыт, действует modal pause rule.

## Функциональность первого релиза

- Показывает название станции.
- Показывает доступные станционные действия.
- Позволяет открыть экран торговли кнопкой `Trade`.
- Позволяет открыть финансовую сводку/операции кнопкой `Finance`.
- Позволяет открыть диалоги с представителями станции.
- Позволяет купить и установить Drilling Unit, если станция предоставляет этот сервис.
- Позволяет открыть окно `Hire` для найма экипажа.
- Позволяет открыть окно `Contracts` для пассажирских контрактов.
- Позволяет вернуться на `GameSessionScreen`, если состояние стыковки сохраняется.
- Позволяет выполнить отстыковку как станционное действие без отдельной module command.

## UI первого релиза

Минимальные кнопки:

- `Trade` - открыть экран торговли станции.
- `Finance` - открыть финансовую сводку/операции станции.
- `Representatives` или `Talk` - открыть диалоги представителей станции.
- `Install Drilling Unit` - купить и установить mining module.
- `Hire` - открыть наём экипажа.
- `Undock` - отстыковаться от станции.
- `Back` - вернуться к карте, если состояние стыковки сохраняется.
- `Contracts` - открыть пассажирские контракты (выделено из `Hire`; отдельная кнопка вне исходной схемы из шести кнопок выше).

## Статус реализации (MVP)

Реализовано:

- Открытие автоматически после первого успешного `navigation.dock` в сессии (`GameSessionScreen.ConsumePendingAutoTransition`, опрашивается раз в кадр из `SkiaWindow.PollGameSessionAutoTransition` — единственный `ScreenEvent` здесь, не порождаемый напрямую input-обработчиком, так как успешный dock узнаётся только из следующего снапшота).
- Повторное открытие левым кликом по карте — по станции, к которой корабль пристыкован, либо по самому кораблю игрока, пока он пристыкован (маркеры физически почти совпадают после дока, см. `Docs/FirstRelease/Mechanics/Docking.md` и приоритет выбора объекта в `ScreenCatalog.md`/§54.9 основного requirements-документа).
- Панель `1400×900` (стандарт игровых окон), закрытие `×`/`Escape`/кликом по затемнённому фону вне панели — без отмены самой стыковки; `Back` из списка кнопок выше реализован именно так (не отдельной кнопкой).
- Modal pause rule — как у любого другого модального окна поверх сессии (`PushModalAsync`/`PopModalAsync`, без собственной speed-логики).
- Кнопки `Trade`, `Hire` и `Contracts` — реальные, кликабельные (не placeholder-строки): открывают `TradeScreen`/`HireScreen`/`ContractsScreen` (все заглушки) вложенным modal поверх `Station`, тем же `PushModalAsync`/`PopModalAsync`, что и `GameMenu → Save/Load`. Закрытие возвращает на `Station`. `Contracts` выделен из исходного `Hire` (наём экипажа vs. пассажирские контракты — разные механики) и занимает новый ряд `6` панели, добавленный после исходных шести рядов, а не переиспользующий чей-то старый. Детали: `Docs/FirstRelease/Screens/Trade.md`, `Docs/FirstRelease/Screens/Hire.md`, `Docs/FirstRelease/Screens/Contracts.md`.
- Кнопка `Finance` тоже реальная — но, в отличие от `Trade`/`Hire`/`Contracts`, открывает не новый экран, а уже существовавший `FinanceScreen` (ранее доступный только с кнопки `F`/`Ctrl+F` на панели механик `GameSessionScreen`). Детали: `Docs/FirstRelease/Screens/Finance.md`.

Не реализовано — экран показывает placeholder-строки "not available yet" вместо этого:

- Название станции и список доступных станционных действий (данные не читаются из snapshot).
- Кнопки `Representatives`, `Install Drilling Unit`, `Undock` — сейчас это статичные текстовые строки, не интерактивные элементы (в отличие от `Trade`/`Hire`/`Finance`/`Contracts`, см. выше).
- Собственно отстыковка (Undock) — нигде не реализована, ни как кнопка здесь, ни как authoritative-действие в Engine.

## Архитектурные требования

- Экран не должен напрямую обращаться к Engine.
- Все действия, меняющие authoritative state, должны идти через `IGameSessionConnection`.
- Покупка/установка Drilling Unit является станционным authoritative-действием.
- Принятие пассажирского контракта является станционным authoritative-действием.
- Отстыковка меняет authoritative state, но не является module command первого релиза.
- Экран должен получать только serializable/session state, пригодный для будущей network boundary.
- Открытие экрана станции должно приостанавливать authoritative simulation через существующий modal pause mechanism.
