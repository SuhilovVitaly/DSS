# Hire

Статус: экран не реализован.

## Назначение

Окно найма и пассажирских контрактов на станции. Открывается из `Station`.

## Функциональность первого релиза

- Показывает доступные пассажирские контракты.
- Позволяет принять контракт, если на корабле есть свободная каюта.
- Показывает причину недоступности контракта, если свободных кают нет.
- Найм экипажа как сложная система остается за рамками первого релиза; в MVP окно обслуживает пассажирские контракты.
