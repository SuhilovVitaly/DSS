# Склад станции

Статус: обновлено моделью размера станции и производящей экономики, требует реализации.

## Цель

Станционный склад задает конечное количество ресурсов, товаров и будущих модулей, доступных для торговли в первом релизе. Склад также связан с размером станции и производящими модулями, потому что они определяют ценовые коэффициенты.

## Решения первого релиза

- Склад станции конечный.
- У каждой станции есть набор ресурсов/товаров/модулей и количества.
- Номенклатура делится на `Resource`, `Good` и `Module`.
- В первом релизе стартовая станция имеет явный склад, а не случайно сгенерированный.
- Случайная генерация `20..500` остается fallback только для станций без explicit inventory.
- Генерация товаров станции должна быть детерминированной относительно `masterSeed` и идентичного состояния мира.
- `Credits` станции генерируются отдельно по правилам `Money.md`.
- `Fuel` на станции является доступным товаром/ресурсом для заправки, но при покупке игроком попадает только в бак двигателя, не в cargo container.

## Стартовая станция

Стартовая станция стартового сценария имеет размер `Large` / `Большой`.

Явный склад стартовой станции:

| Категория | Номенклатура | Количество |
| --- | --- | ---: |
| `Good` | `Food Rations` | `500` |
| `Good` | `Energy Cells` | `350` |
| `Good` | `Fuel` | `700` |
| `Resource` | `Ice` | `320` |
| `Resource` | `Iron Ore` | `410` |
| `Resource` | `Silicon` | `70` |
| `Resource` | `Magnesium Ore` | `120` |

Явный склад стартовой станции не должен быть перезаписан fallback-генерацией.

## Цены

Каждая торгуемая номенклатура имеет `BasePriceCredits`.

Базовые цены ресурсов:

| Resource | Id | Base price |
| --- | --- | ---: |
| `Ice` | `RES-2001` | `10 Credits` |
| `Iron Ore` | `RES-2002` | `5 Credits` |
| `Silicon` | `RES-2003` | `40 Credits` |
| `Magnesium Ore` | `RES-2004` | `30 Credits` |

Базовые цены товаров:

| Good | Id | Base price |
| --- | --- | ---: |
| `Water` | `ITM-3001` | `14 Credits` |
| `Steel` | `ITM-3002` | `40 Credits` |
| `Energy Cells` | `ITM-3003` | `50 Credits` |
| `Fuel` | `ITM-3004` | `10 Credits` |
| `Protein mass` | `ITM-3005` | `110 Credits` |

- Для `Food Rations` и продаваемых модулей базовые цены должны быть добавлены отдельным балансным решением до реализации.
- Итоговая цена товара на станции рассчитывается как `basePrice * allApplicableStationFactors`.
- Минимальный набор факторов: коэффициент размера станции по категории номенклатуры и все активные station events / buffs / debuffs.
- Итоговая цена округляется до ближайшего целого `Credits`.
- Для authoritative money path коэффициенты должны храниться без `float`/`double`, например fixed-point (`1000 == 1.0`).
- Старый `stationPriceCoefficient 0.5..2.0` считается предыдущей MVP-моделью и заменяется набором explicit факторов.
- Цена зависит от событий станции и от производящих модулей станции.

## Производящие модули

- Станция может иметь производящие модули.
- Каждый производящий модуль выпускает один или несколько `Good`.
- Каждый производящий модуль требует один или несколько входных `Resource`.
- Потребность в сырье хранится как коэффициент на входном ресурсе производящего модуля.
- Если ресурс является входом хотя бы одного производящего модуля станции, для цены ресурса применяется коэффициент потребляемого ресурса.
- Если ресурс не потребляется производящими модулями станции, для цены ресурса применяется коэффициент общего ресурса.
- Точная формула расхода сырья по коэффициенту потребности требует отдельного балансного решения.

## Требования первого релиза

- Покупка cargo-товара уменьшает количество товара на складе станции.
- Продажа cargo-товара увеличивает количество товара на складе станции.
- Нельзя купить больше cargo-товара, чем есть на складе станции.
- Количество товара на складе станции не может уходить ниже `0`.
- Заправка `Fuel` уменьшает доступный запас `Fuel` станции, если запас `Fuel` моделируется как конечный товар станции.
- Сохранение/загрузка должны сохранять склад станции, размер станции, производящие модули и активные ценовые модификаторы.
- Продажа `Resource` игроком выполняется упаковками по `100` kg.
- Продажа `Good` игроком выполняется упаковками по `10` kg.
- Продажа `Module` игроком выполняется поштучно.
