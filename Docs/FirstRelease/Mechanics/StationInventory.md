# Склад станции

Статус: решение первого релиза принято, требует реализации.

## Цель

Станционный склад задает конечное количество товаров, доступных для торговли в первом релизе.

## Решения первого релиза

- Склад станции конечный.
- У каждой станции есть набор товаров и количества.
- В первом релизе стартовые товары станции: `Energy Cells`, `Fuel`, `Ice`.
- Для первого релиза все товары станции генерируются в случайном количестве от `20` до `500` единиц включительно.
- Генерация товаров станции должна быть детерминированной относительно `masterSeed` и идентичного состояния мира.
- `Credits` станции генерируются отдельно по правилам `Money.md`.
- `Fuel` на станции является доступным товаром/ресурсом для заправки, но при покупке игроком попадает только в бак двигателя, не в cargo container.

## Цены

Базовые цены первого релиза:

| Товар | Base price |
| --- | ---: |
| `Energy Cells` | `200 Credits` |
| `Fuel` | `200 Credits` |
| `Ice` | `30 Credits` |

- У каждой станции есть ценовой коэффициент станции в диапазоне от `0.5` до `2.0` включительно.
- Итоговая цена товара на станции рассчитывается как `basePrice * stationPriceCoefficient`.
- Итоговая цена округляется до ближайшего целого `Credits`.
- Коэффициент станции генерируется детерминированно относительно `masterSeed` и состояния мира, если не задан явно.
- В будущих версиях цены будут зависеть от событий на станции и от того, что станция производит.

## Требования первого релиза

- Покупка cargo-товара уменьшает количество товара на складе станции.
- Продажа cargo-товара увеличивает количество товара на складе станции.
- Нельзя купить больше cargo-товара, чем есть на складе станции.
- Количество товара на складе станции не может уходить ниже `0`.
- Заправка `Fuel` уменьшает доступный запас `Fuel` станции, если запас `Fuel` моделируется как конечный товар станции.
- Сохранение/загрузка должны сохранять склад станции и ценовой коэффициент станции.

## Минимальные товары первого релиза

- `Energy Cells`.
- `Fuel`.
- `Ice`.
