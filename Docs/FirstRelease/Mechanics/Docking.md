# Стыковка

Статус: решение первого релиза принято, требует реализации.

Связанные документы: `CommandPanels.md`, `TacticalMapAndManeuvering.md`, `Station.md`.

## Цель

Стыковка открывает доступ к станции, торговле, заправке и диалогам представителей станции.

## Решения первого релиза

- Стыковка не происходит автоматически при достижении станции.
- `Dock` является командой Navigation Computer: `navigation.dock`.
- Команда `Dock` проходит через module-addressed command model.
- Отстыковка в первом релизе является станционным действием, а не отдельной module command.
- Стыковка возможна только со станциями.
- Доступная дистанция `Dock`: `< 200 km`.
- Значение `200 km` должно быть параметром command definition команды `Dock` навигационного компьютера, а не hardcoded-числом в logic/UI.
- Перед `Dock` корабль должен быть синхронизирован со станцией по скорости и направлению.
- При успешном `Dock` корабль физически синхронизируется со станцией: получает позицию/скорость/движение станции по модели пристыкованного состояния.
- Local offset корабля относительно станции после `Dock` использует старую модель синхронизации: `(1, 1)` world unit.
- После успешного `Dock` экран станции открывается автоматически.
- После успешной отстыковки игрок возвращается к обычному режиму полета на `GameSessionScreen`.

## Требования первого релиза

- Engine должен authoritative хранить состояние стыковки корабля игрока.
- Состояние стыковки должно сохраняться и загружаться.
- Пока корабль пристыкован, станционные действия должны знать station id.
- Команда `Dock` должна валидировать цель: station object id обязателен.
- Команда `Dock` должна валидировать дистанцию до станции через параметр команды `Dock` навигационного компьютера.
- Команда `Dock` должна валидировать, что скорость и направление корабля синхронизированы со станцией.
- Отстыковка должна быть доступна только если корабль уже пристыкован.
- Если цель не станция, дистанция больше допустимой или стыковка невозможна, Engine отклоняет команду с понятным результатом.
- При стыковке движение корабля больше не рассчитывается как независимое маневрирование, пока корабль остается пристыкованным.
