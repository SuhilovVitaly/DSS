# Пассажирские контракты

Статус: решение первого релиза принято, требует реализации.

Связанные документы: `CrewAndHabitation.md`, `Station.md`, `StationDialogues.md`, `Money.md`.

## Цель

Пассажирские контракты дают игроку станционную активность, связанную с перевозкой людей, и используют уже введенную модель кают жилого модуля.

## Решение первого релиза

- Пассажиры являются active gameplay entity первого релиза.
- Контракт на перевозку пассажира можно получить на станции.
- Пассажир занимает свободную каюту так же, как член экипажа.
- Стартовый корабль имеет `living-quarters.mk1` с `cabines = 2`.
- На старте на корабле есть главный герой, занимающий `1` каюту.
- Без установки дополнительных жилых модулей у стартового корабля остается `1` свободная каюта для пассажира.
- Контракты должны учитывать доступную вместимость кают до принятия.

## Требования первого релиза

- Станция может предлагать контракт на перевозку пассажира.
- Игрок может принять контракт только если на корабле есть свободная каюта.
- Принятый пассажир добавляется в список людей на корабле.
- Сохранение/загрузка должны сохранять активные пассажирские контракты и пассажиров на корабле.
- UI станции должен показывать доступность пассажирского контракта и причину недоступности, если свободных кают нет.
- Выплата, маршрут и условия завершения контракта могут быть минимальными, но должны быть authoritative state, а не только UI-флагом.

## За рамками первого релиза

- Сложная репутация пассажиров.
- Ветвящиеся диалоги пассажиров.
- Несколько классов кают.
- Детальная экономика пассажирских перевозок.
