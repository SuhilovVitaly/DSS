# Экипаж, пассажиры и жилой модуль

Статус: решение первого релиза принято, требует реализации.

Связанные документы: `TetrarchClass.md`, `PassengerContracts.md`.

## Цель

Экипаж и пассажиры являются людьми на корабле. Для их размещения кораблю нужен жилой модуль с каютами.

## Решения первого релиза

- Экипаж - это люди, а не только UI/диалоговый список.
- Стартовый экипаж первого релиза: `1` персонаж, главный герой.
- Пассажиры являются active gameplay entity первого релиза.
- Пассажирские контракты можно получить на станции.
- Пассажиры используют ту же базовую модель размещения, что и экипаж.
- Для размещения людей нужен `Living quarters`.
- Стартовый корабль Tetrarch содержит `living.quarters.mk1`.
- `Living quarters MK I` содержит `cabines = 2`.
- Главный герой занимает одну каюту; без дополнительных жилых модулей остается одна свободная каюта под пассажира.
- Вместимость людей на корабле определяется количеством доступных кают.
- Человек не может находиться на корабле сверх доступной вместимости кают, если отдельное требование не задаст аварийное/временное размещение.
- Диалоги с членами экипажа доступны только для людей, находящихся на корабле.

## Требования первого релиза

- Engine должен хранить список людей на корабле или подготовить authoritative модель, достаточную для проверки вместимости кают.
- Новая игра создает на корабле одного персонажа: главного героя.
- Главный герой занимает одну каюту из `2` доступных кают `living.quarters.mk1`.
- Пассажир может быть добавлен на корабль через станционный контракт только при наличии свободной каюты.
- Сохранение/загрузка должны сохранять состав экипажа/пассажиров, если они входят в active session state первого релиза.
- UI должен иметь доступ к списку членов экипажа и пассажиров.
- Жилой модуль стартового корабля обеспечивает `2` каюты для экипажа/пассажиров.
