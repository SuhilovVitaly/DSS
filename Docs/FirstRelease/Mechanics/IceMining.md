# Добыча льда

Статус: решение первого релиза принято, требует реализации модуля и команд.

Связанные документы: `TetrarchClass.md`, `CommandPanels.md`, `CargoHold.md`, `Station.md`.

## Цель

Игрок добывает лед с астероидов, грузит его в контейнер и продает на станциях.

## Уже существующая основа

- В мире есть `Asteroid`.
- В данных есть `module.drilling-unit.basic`.
- В новой стартовой комплектации Tetrarch Class `Drilling Unit` отсутствует.
- Есть cargo/container module для перевозки добытого ресурса.

## Решение первого релиза

- Mining capability реализуется через отдельный модуль Drilling Unit.
- Базовый module type первого релиза: `module.drilling-unit.basic`.
- Игрок не получает Drilling Unit бесплатно; его можно купить и установить на станции.
- До установки Drilling Unit команды добычи недоступны.
- Для модуля реализуются команды `mining.extract-ice` и `mining.stop-extraction`.
- Добыча льда является module-addressed command flow, подтверждаемым Engine.
- Базовое время цикла Drilling Unit в MVP: `10000 ms`.
- Mining range первого релиза: `100 km`.
- Перед добычей asteroid должен быть просканирован; для подтверждения льда используется `scanner.structural-scan`.
- Запас льда на asteroid конечный и генерируется случайно от `100` до `5000` единиц включительно.
- Объем добычи за цикл Drilling Unit является параметром модуля: случайное значение от `100` до `200` единиц включительно.
- Добытый лед добавляется в грузовой отсек как cargo item `Ice`.

## Параметры Drilling Unit

| Параметр | Значение MVP |
| --- | ---: |
| `baseCycleTimeMs` | `10000` |
| `miningRangeKm` | `100` |
| `iceExtractionUnitsPerCycleMin` | `100` |
| `iceExtractionUnitsPerCycleMax` | `200` |

## Asteroid ice stock

- Каждый asteroid, пригодный для добычи льда, имеет конечный запас `Ice`.
- Начальный запас `Ice` генерируется случайно в диапазоне `100..5000` единиц.
- Генерация должна быть deterministic относительно `masterSeed` и состояния мира.
- Когда запас льда на asteroid становится `0`, `mining.extract-ice` больше не может добывать лед с этого asteroid.

## Команды

| Команда | Цель | Условия |
| --- | --- | --- |
| `mining.extract-ice` | `Asteroid` | На корабле есть установленный и рабочий `module.drilling-unit.basic`; выбран asteroid; asteroid просканирован через `scanner.structural-scan`; scan result подтверждает доступный лед; дистанция до asteroid `<= 100 km`; скорость и направление синхронизированы с asteroid; в cargo есть свободная вместимость; asteroid содержит доступный лед |
| `mining.stop-extraction` | Нет | На корабле есть активный mining cycle |

## Требования первого релиза

- Добыча льда доступна только у астероидов, удовлетворяющих условиям добычи.
- Добыча должна использовать установленный и рабочий Drilling Unit.
- Если модуль отсутствует, поврежден или не готов, команда `mining.extract-ice` недоступна.
- Если asteroid не выбран, выбран неверный тип объекта или объект дальше `100 km`, команда отклоняется Engine.
- Если asteroid не просканирован через `scanner.structural-scan`, команда отклоняется Engine.
- Если scan result не подтверждает доступный лед, команда отклоняется Engine.
- Если скорость и направление корабля не синхронизированы с asteroid, команда отклоняется Engine.
- Если cargo capacity заполнена, добыча не начинается или останавливается с понятным feedback.
- За один цикл `10000 ms` Drilling Unit добывает случайное количество `Ice` от `100` до `200` единиц, ограниченное остатком льда на asteroid и свободным cargo capacity.
- Добытый лед добавляется в грузовой отсек как товар.
- Добыча не может превысить cargo capacity и не может добыть больше остатка льда на asteroid.
- Добыча должна иметь понятный feedback: активна, остановлена, завершена, нет места, нет подходящего астероида, нет mining module, asteroid не просканирован, нет льда.
