# Добыча льда

Статус: требует проектирования и реализации, но `Drilling Unit` уже есть в данных стартового корабля.

## Цель

Игрок добывает лед с астероидов, грузит его в контейнер и продает на станциях.

## Уже существующая основа

- В мире есть `Asteroid`.
- В стартовом корабле по requirements есть `Drilling Unit`.
- В данных есть `module.drilling-unit.basic`.
- Есть cargo/container module для перевозки добытого ресурса.

## Требования первого релиза

- Добыча льда доступна только у астероидов, удовлетворяющих условиям добычи.
- Добыча должна использовать установленный drilling module.
- Добытый лед добавляется в грузовой отсек как товар.
- Добыча не может превысить cargo capacity.
- Добыча должна иметь понятный feedback: активна, завершена, нет места, нет подходящего астероида, нет drilling unit.

## Требует решения

- Нужно ли сканировать астероид перед добычей.
- Является ли лед бесконечным ресурсом астероида в MVP или у астероида есть конечный запас.
- Добыча требует стыковки/синхронизации с астероидом или достаточно находиться в радиусе.
- Добыча занимает игровое время или происходит мгновенно в MVP.
