# Экипаж корабля и диалоги

Статус: решение первого релиза принято, требует реализации.

Связанный документ: `CrewAndHabitation.md`.

## Цель

Игрок может говорить с членами экипажа корабля, чтобы получать информацию, атмосферу, подсказки и будущие сюжетные/игровые развилки.

## Решения первого релиза

- Экипаж - это люди на корабле.
- Члены экипажа размещаются в каютах жилого модуля.
- Диалоги первого релиза линейные.
- Узловые деревья выбора ответов не входят в MVP первого релиза.
- Любой открытый диалог является modal screen и ставит authoritative simulation на паузу.

## Требования первого релиза

- У игрока должен быть доступ к списку членов экипажа.
- Игрок может открыть диалог с выбранным членом экипажа.
- Диалог должен показывать линейную последовательность реплик.
- Диалог должен быть доступен только для члена экипажа, находящегося на корабле.
- Диалог не должен нарушать architectural boundary: состояние диалога должно передаваться как сериализуемые данные, если оно становится частью authoritative/session state.

## Требует решения

- Стартовый состав экипажа.
- Где открывается UI списка экипажа.
