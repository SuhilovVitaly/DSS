# Грузовой отсек

Статус: частично описано в требованиях, частично представлено в данных.

Основной источник: раздел 46 `deep_space_saga_engine_requirements.md`.

## Цель

Корабль игрока должен перевозить cargo-товары: добытый лед, `Energy Cells` и другие торговые товары первого релиза.

## Решение первого релиза

- `Energy Cells` являются cargo item.
- `Energy Cells` можно складировать в container module, покупать и продавать.
- `Energy Cells` используются реактором/генератором для питания корабельных модулей.
- `Fuel` не хранится в грузовом отсеке.
- `Fuel` хранится только во внутренних баках двигателя.
- Cargo/container module отвечает только за перевозимые cargo-товары.

## Уже существующая основа

- `module.container.basic` имеет `cargoCapacityKg`.
- `item.energy-cells` уже существует как item type.
- Основной requirements-документ задает вместимость по массе через `CapacityKg`.
- Стартовый корабль содержит container module.

## Требования первого релиза

- Груз хранится в container/cargo module корабля.
- Вместимость считается по массе, без литров, объема и плотности.
- Для штучных товаров хранится целое количество единиц.
- Масса товара вычисляется как `quantity * unitMassKg`.
- Суммарная масса груза не может превышать вместимость.
- UI должен показывать список товаров, количество и занятость грузовой вместимости.
- Покупка `Energy Cells` занимает cargo capacity.
- Расход `Energy Cells` реактором/генератором уменьшает количество `Energy Cells` в cargo.
- Заправка `Fuel` не должна менять массу/содержимое грузового отсека в MVP.

## Минимальные товары-кандидаты

- `Ice` - товар для добычи и продажи.
- `Energy Cells` - товар для реактора/электросистемы.
- Базовые станционные товары будут определены отдельно, если понадобятся для торгового MVP.

## Требует решения

- Нужно ли в первом релизе хранить груз по отдельным контейнерам или достаточно общего cargo pool корабля.
