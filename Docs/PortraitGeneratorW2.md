# W2: цельная голова и отдельная общая шея

W2 сохранён и открывается явной передачей пути в `TempCharacterImageScreen`; по умолчанию теперь используется [W4](PortraitGeneratorW4.md). Случайный портрет появляется при открытии; клик по нему или кнопка «Случайный портрет» меняет сочетание. Стрелки отдельно выбирают голову, причёску и костюм. Шея одна: её кнопка только показывает слой. Справа показаны четыре компонента. Пресеты W2 сохраняются отдельно в `temp-character-w2.json`.

Набор: `src/DeepSpaceSaga.Client/Images/Persons/W2`.

| Папка | Содержимое |
|---|---|
| `Heads` | 3 новые головы: лицо, овал, подбородок, уши и все черты одним PNG; шея удалена |
| `Neck` | 1 отдельно сгенерированная общая шея без лица и подбородка |
| `Clothes` | Копии 3 совместимых костюмов W1 |
| `Hair` | 5 новых причёсок: французское каре, медный андеркат, две светлые косы, каштановые кудри, платиновый помпадур |
| `Sources` | 9 новых исходников без референсов |
| `Generated` | 15 примеров, все 45 сочетаний, головы с шеей без волос, превью окна |

Рабочие прозрачные PNG имеют размер 1024×1024. Сборка: **шея → голова → костюм → волосы**. Всего 45 сочетаний. Кожа и черты внутри каждой головы не смешиваются с другими головами. Регистрация головы — единое равномерное масштабирование; волосы согласованы с общей посадкой. Верх шеи скрыт за головой, низ перекрыт воротником. Три костюма скопированы без изменения исходников. W и W1 сохранены.

Графика создана встроенным `image_gen` без референсов. Запросы находятся в `tools/DeepSpaceSaga.PortraitAssets/w2-prompts.json`. Техническая подготовка прозрачных слоёв — `WholeHeadAssets.cs`.

```powershell
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- w2 src/DeepSpaceSaga.Client/Images/Persons/W2
dotnet run --project tools/DeepSpaceSaga.PortraitAssets -- preview src/DeepSpaceSaga.Client/Images/Persons/W2
```

В игру копируются только рабочие PNG, `parts.json` и `portrait-style.json`. `Sources` и `Generated` исключены из сборки и публикации. Для запуска игры авторская утилита не нужна.
