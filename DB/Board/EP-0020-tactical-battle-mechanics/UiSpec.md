# EP-0020 — интерфейс механик

Дополнение к [DesignSpec EP-0019](../EP-0019-tactical-battle-ui-redesign/DesignSpec.md). Всё, что здесь не названо, остаётся как в EP-0019. Этот документ — единственный источник вида механик эпика: координаты, цвета, размеры шрифтов, тексты и состояния. M1 «Уклонение и сознание» — §1–§7, M2 «Ловушки» — §8–§14, M3 «Аномалии» — §15–§21, M4 «Пилот и сборка» — §22–§26.

Координаты — абсолютные единицы макета 1280×720 (масштаб `S = H/720`, при 1920×1080 — ×1,5), уже со сдвигом деталей +24 из EP-0019. Обозначения EP-0019: детали стрельбы — колонка `1040…1274`, `x0 = 1050`, `x1 = 1264`, `mid = 1157`; нижняя граница деталей стрельбы `DB = 250`, зона действия `Action = (1040, 278)…(1274, 370)`. Текст рисуется функцией `T` EP-0019 (базовая линия — указанная `y`), поля — `BoxText`, кнопки — `Button`.

Макет утверждён пользователем (D-13) при штрафе 20 и цене 10; в интерфейсе числа берутся из снимка `Rules.Evasion`.

## 4. Карточка пилота

- **Строка «Сознание».** Значение из снимка; цвет значения `Red`, если оно меньше минимума; полоса `Green` по доле от 100.
- **Фаза стрельбы, дрон уклоняется.** Значок «Уклонение» на месте значка цели: фон `PurpleDark`, рамка `Purple` α 200 толщиной 0,8, текст `Purple` 9 жирный. Геометрия значка — как в EP-0019.
- **Результаты, свой уклонившийся дрон.** Значок «уклонение» в тех же цветах вместо «не стрелял(а)».

## 5. Карта и карточка наведения

- **Кольцо уклонения.** Окружность радиуса 15 с центром в маркере юнита, `Purple`, толщина 1,6, пунктир 3/3. Рисуется после маркера, до подписей.
  - Фаза стрельбы: только свои дроны с планом уклонения.
  - Полёт залпа и результаты: все дроны с шагом `Evading` в этом залпе.
- **Карточка наведения.** Вместо значка состояния — «Уклонение»: текст 10,5 жирный `Purple`, фон `PurpleDark`, рамка `Purple` 1. Прямоугольник шириной «текст + 12» прижат к правому краю карточки с отступом 8, `y` от верха карточки 25…41. Для противника значок появляется только после разрешения залпа.
- **До разрешения залпа** уклонение противника не показывается нигде, а его шанс в прогнозах считается без штрафа (D-08).

## 12. Залп и результаты

### 12.1. Очерёдность огня (EP-0019 §6.4)

- Выстрел с `Decoyed`, цель — свой дрон: шанс показывается Bold `Green` (это уже шанс с ловушкой).
- Выстрел с `Decoyed`, цель — дрон противника: показывается `ChanceWithoutDecoy` в цвете строки. Ловушка противника в полёте не раскрывается.

### 12.2. Выноски на карте (фаза результатов)

- Для каждого выстрела с `Decoyed` и без попадания — `Callout` «Ловушка · промах `<Стрелок>`» (`edge = Green`, текст `Green`) у цели, своей или противника. Рисуется после выносок брони, до маркеров.
- Кандидаты центра относительно `W` цели: `(0, −38)`, `(0, 44)`, `(hw + 20, 10)`, `(−hw − 20, 10)`, `(0,6·hw, −38)`, `(0,6·hw, −60)`, `(0, −60)`, `(0, 64)`, где `hw = (ширина(текст, 12) + 14)/2`.
- Побеждает первый кандидат, чей прямоугольник `x ± hw × y − 17 … y + 2` не пересекает занятые прямоугольники и, расширенный на 10, не содержит ни маркера юнита, ни точки `q` метки ловушки. Если подходящего нет — первый кандидат.

### 12.3. Панель результата (EP-0019 §6.5)

Если показанный выстрел имеет `Decoyed`:
- «ловушка цели» 10,5 `Green` по правому краю `(1264, 128)`;
- «`<ChanceWithoutDecoy>` → `<Chance>`» Bold 12 `Green` по правому краю `(1264, 144)`.

### 12.4. Карточка наведения

Для дрона из `DecoysLaunched`, только в фазах, где видна его метка (§11), — значок «Ловушка» в геометрии M1 §5: текст 10,5 жирный `Green`, фон `GreenDark`, рамка `Green` 1. Значок «Уклонение» важнее, но вместе они не встречаются (D-16).

## 16. Слой поля

### 16.1. Значение и нормировка

Для пикселя `(px, py)` холста `Wd × H` точка макета `d = ((px + 0,5)/S, (py + 0,5)/S)`, мировая точка `w = ((d.x − ox)/scale, (d.y − oy)/scale)`. Для каждого вида `F, gx, gy = FieldWithGradient(вид, w)`; `t = clamp(ln(max(F, 100)/100) / ln 2, 0, 1)`. Градиент на экранный пиксель: `g_px = g / (scale × S)`.

### 16.2. Рельефная тень

```
slope  = atan(k · |g_px|);  aspect = atan2(−g_px.x, g_px.y)
shade  = clamp(sin45°·cos(slope) + cos45°·sin(slope)·cos(315° − aspect), 0, 1)
factor = clamp(1 + (shade − sin45°) · gain, 0,45, 1,5)
color  = min(1, base · factor)   (по каналам, 0..1)
```

Температурная: `k = 0,35`, `gain = 1,6`. Пылевая: `k = 0,5`, `gain = 2,2`.

### 16.3. Фактура температурной аномалии

`tex = 0,45 + 0,75 · (0,6 · n(w.x/4, w.y/4) + 0,4 · n(w.x/12 + 50, w.y/12 + 50))`, где `n` — value-шум:
- `ix = ⌊x⌋`, `iy = ⌊y⌋`, `fx = x − ix`, `fy = y − iy`, сглаживание `f = f²(3 − 2f)`;
- `hash(i, j)`: `h = (uint)(i·374761393 + j·668265263 + 1013904223)` (переполнение по модулю 2³²); `h = (h ^ (h >> 13)) · 1274126177`; `h ^= h >> 16`; значение `(h & 0xFFFFFF) / 0xFFFFFF`;
- `n = a + (b − a)·fx + (c − a)·fy + (a − b − c + d)·fx·fy` для углов `a = hash(ix, iy)`, `b = hash(ix+1, iy)`, `c = hash(ix, iy+1)`, `d = hash(ix+1, iy+1)`.

Базовый цвет: `Red3(t) × tex` (каналы с отсечением 255 до тени). Пылевая без фактуры: `Hot3(t)`.

### 16.4. Смешение

Пиксель вида считается, только если его `t > 0,002`; иначе вклад 0. `field = 1 − (1 − heat)·(1 − dust)`; итог на карте `1 − (1 − field)·(1 − MapBg)`. Контуров, изолиний и подписей уровней нет.

### 16.5. Порядок слоёв

`MapBg` → слой поля (§16.1–16.4) → сетка EP-0019 §8.1 с режимом `Lighten` → остальные слои EP-0019 §4. В фазе стрельбы после сектора выбранного стрелка (EP-0019 §8.6) слой поля **без** подложки `MapBg` рисуется ещё раз в режиме `Screen` с отсечением по контуру сектора.
