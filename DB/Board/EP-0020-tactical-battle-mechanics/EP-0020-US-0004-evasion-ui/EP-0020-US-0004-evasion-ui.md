# Уклонение в интерфейсе боя

## Входное техническое задание

D-08, D-09, D-13. Интерфейс EP-0019 должен быть полностью реализован и принят (EP-0019-US-0006-TK-0002-view-acceptance). Вид задаёт только [UiSpec](../UiSpec.md): геометрия, цвета, тексты, состояния.

## User story

Как игрок, я хочу в панели стрельбы и клавишей E выбирать уклонение, видеть сознание пилотов и узнавать после залпа, кто из противников уклонялся.

## Dependencies

[EP-0020-US-0002-evasion-resolution](../EP-0020-US-0002-evasion-resolution/EP-0020-US-0002-evasion-resolution.md), [EP-0019-tactical-battle-ui-redesign](../../EP-0019-tactical-battle-ui-redesign/Documentation.md) (весь эпик)

## Completion evidence

- Панель стрельбы в трёх состояниях, кнопка «Уклониться [E]», клавиша E.
- Карточки показывают сознание из снимка.
- Уклонение противника видно на карте и в карточке наведения только в залпе и результатах.
- Проверки вида EP-0019 зелёные; новые состояния покрыты растровыми пробами UiSpec.

## Acceptance criteria

- **US4-AC1.** Клавиша E и кнопка переключают уклонение выбранного дрона; выбор цели снимает уклонение; при сознании < минимума кнопка недоступна, E ничего не делает. Запрос содержит `Evade` для уклоняющихся.
- **US4-AC2.** Панель стрельбы рисует состояния «план выстрела», «план уклонения», «нет целей» по UiSpec §2–3; карточка — значок «Уклонение» и сознание из снимка (§4); на карте — кольцо (§5). Растровые пробы UiSpec §7 проходят.
- **US4-AC3.** В залпе и результатах дроны с шагом `Evading` получают кольцо; карточка наведения показывает «Уклонение»; журнал — «уклонение». До разрешения залпа уклонение противника нигде не показывается; прогноз шанса по нему — без штрафа.
- **US4-AC4.** Проверки вида и регрессионные снимки EP-0019 для сцен без стрельбы проходят без изменений; сцены стрельбы отличаются от прежних снимков только в областях UiSpec §7; ожидания и снимки изменённых сцен обновлены по правилу US-0004 TK-0004.

## Non-goals

Анимации переключения, звук, отдельная клавиша «не стрелять».

## Invariants

Остальной вид EP-0019 не меняется. Клиент не вычисляет шанс с уклонением сам — берёт `ChanceIfEvading` из снимка.

Ожидает утверждения эпика пользователем (см. [открытые вопросы](../Documentation.md#открытые-вопросы)).
