## Ключевые assumptions и release risks

- Windows x64 — первая RC; другие платформы не получают ложного PASS. Аудио — изолированный waveOut backend и silent fallback; первоначальные оригинальные procedural assets требуют ручной художественной/слуховой приёмки.
- 5 станций, 4 дополнительных passenger места, 8 основных товаров, 2 обычные пиратские группы без respawn; числа — baseline в границах сокращённого плана.
- Deadline считается calendar time, pursuit — motion time. Arrival ровно в deadline успешен; cancelled passengers/cargo высаживаются на следующей человеческой станции.
- Wage debt не увольняет crew и не блокирует мирный доход. Абсолютное банкротство не гарантирует спасение; нормальный recovery после потери крыла обязателен и проверяется.
- Crash во время боя возвращает к последнему durable checkpoint; обычный exit применяет последствия. Не заявлять перманентность ещё не записанного состояния; сохранение внутри боя вне scope.
- Контентный баланс/XP/цены — исходные настройки, принимаются по whole-voyage и 60–120 minute playtests.
- Публикация требует отдельного поручения. Native только на проверенном меньшем мониторе; отсутствие hardware/player/audio означает OPEN, не PASS.
