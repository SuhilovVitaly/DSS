## Актуальный контракт груминга

Игрок получает оплату bounty только на станции заказчика; добыча отделена от денег. После победы открыта тактическая карта: клик по Disabled-дрону без подлёта открывает таблицу модулей и сбор расходников; уничтоженный дрон/самоуничтожившийся носитель дают попытку лома. Выход предупреждает об оставленном и завершает сбор. Все результаты и попытки сохраняются без повторного боя, RNG или выдачи.

- Каждый enemy carrier самоуничтожается, когда все **его** дроны Destroyed/Disabled. Не AoE; Disabled-пилоты не гибнут автоматически.
- Модули: один 50%-бросок уничтожения на экземпляр, уцелевшие можно попытаться снять один раз. База25% + личный бонус инженера10–15п.п.; weapon×0.95,engine×1.05. Успех даёт исправный товар только для продажи. Отдельная trophy durability/ремонт/установка не вводятся.
- Ракеты/ловушки: 50%-бросок на весь фактический оставшийся запас каждого типа; сбор отдельными кнопками. Пилоты не предметы и в эти броски не входят.
- Scrap: одна попытка на каждый wreck drone/carrier,25%+инженер10–15п.п.; фиксированный выход по типу из content. Carrier wreck даёт только scrap.
- Cargo по массе; места на целый модуль недостаточно — до броска отказ без расхода попытки/RNG. Трофейные товары имеют catalog mapping и конечных покупателей; оценка цены не является cash/quote.
- Инженер — отдельный живой член экипажа с назначенной ролью и persisted личным бонусом. Пленные — арест/содержание в демо, одна общая свободная каюта на человека, пайки по норме, без жалованья; постоянного резерва2кают нет. Пытки/вербовка — будущий отдельный эпик.
- Bounty без срока/залога, свободная отмена без штрафа/награды. Подтверждённая победа игрока над конкретной группой оплачивается станцией, у которой есть соответствующий заказ, даже без предварительного принятия/после отмены. Одно durable право не дублируется новым contractId. Точные D-36-29…33 и entitlement schema находятся в US1/2.

Решения пользователя и отменённые ранние предложения сохранены ниже в хронологии. Для актуального исполнения приоритет имеют этот раздел, текущие story AC и текущие ticket API/steps; ранние ограничения «только торпеды и лом», «без пленных» и требование новой прочности superseded. Численные content A — baseline плейтеста, не продуктовая приёмка.
