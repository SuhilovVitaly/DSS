## Implementation steps

1. Из frozen actual equipment enumerate slot instances
2. существующее destroyed не допускать, surviving повреждённый component при успехе даёт исправный commodity по D-36-23. Один 50%-бросок уничтожения на instance до показа, результат persisted и скрыт. Проверить source/session/revision, доступность и полную массу до RNG
3. CargoFull не тратит попытку. Одно dismantle испытание на module
4. failure terminal недоступен, success atomic add cargo one item+provenance и terminal Collected. Шанс .2375/.2625 без инженера, weapon .3325… .38 и engine .3675… .42 с инженером. EstimatedValue из catalog base, не active quote. Не присваивать unknown basis ноль, не применять repair или equip.

## Invariants

- Engine владеет шансом/RNG, capacity, деньгами и подтверждённым результатом; UI не вычисляет новый исход.
- Stable BattleId/ObjectId/module slot/command identity, phase и terminal attempt переживают Load. Не reroll и не дублировать cargo/postings.
- Текущий single inventory/PlayerCredits сохраняются; новый trophy только обычный продаваемый item, не отдельный wallet.
- Успешный salvage выдаёт исправный commodity; не вводить прочность 0–100%, ремонт или установку трофея.
- 50%-бросок касается предметов, не пилота. Самоуничтожение не создаёт неоговорённый AoE.
- CargoFull до попытки не тратит RNG/попытку. Generic catalog corruption отклоняется до публикации нового мира.
