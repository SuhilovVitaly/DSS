## Допущения

- **A-01.** Исторические эпики не переписываются. Их статус для демо фиксирует
  новый реестр `DB/Board/README.md` со ссылками на evidence; правится только
  фактически ложное утверждение (EP-0029) и добавляется пометка о замене решения
  (EP-0021), как требует `DocumentationSystem.md` («Историческая точность»).
- **A-02.** Статус в реестре — краткое резюме собственных отчётов эпика и
  `git log`, а не новая приёмка. Продуктовая и native приёмка остаются за владельцем.
- **A-03.** Номера EP-0032…EP-0044 в дорожной карте — резерв под порядок; папки
  этих эпиков не создаются, пока владелец не поручит их нарезку.
- **A-04.** Документационные тикеты используют `layer: documentation` без тестового
  проекта, как EP-0030 US-0005. Проверка — ссылки, ID, `git diff --check`.
- **A-05.** Коммиты делаются по тикетам в ветке `feature/ep-0031-board-and-demo-scope`.
  Push не выполняется без отдельного поручения владельца.
