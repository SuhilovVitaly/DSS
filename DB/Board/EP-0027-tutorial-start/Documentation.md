# EP-0027 — Обучающий старт через тактический бой

Новый игрок без сохранений нажимает «Новая игра» и сразу попадает в Tabletop-бой, тот же, что открывает F8 на карте. Карта солнечной системы открывается только после завершения боя. До этого единственный выход — главное меню, сохранение недоступно.

## Исходное техническое задание

**D-01.** Новый скрытый сценарий «Обучение» (Tutorial), которого нет в списке выбора сценариев.

**D-02.** Запуск обучения сразу открывает Tabletop-бой, который F8 открывает с карты.

**D-03.** Выход на карту солнечной системы возможен только после завершения боя.

**D-04.** До завершения боя единственный выход — главное меню; сохраниться нельзя.

**D-05.** «Новая игра» в главном меню при отсутствии сохранений сразу запускает обучение, без выбора сценария и без карты.

## Решения пользователя

- Экран подготовки боя пропускается. Используется запрос по умолчанию: боевой сценарий `initial`, комплектация по умолчанию, фиксированный seed 1.
- После боя обучения (победа или поражение) доступна только кнопка «На карту»; кнопки нового боя нет.
- Мир обучения — копия сценария Default с полной процедурной солнечной системой.
- Esc в бою обучения открывает существующий диалог подтверждения с текстом «Выйти в главное меню». Подтверждение ведёт в главное меню, сессия закрывается.
- Флаг `Hidden` в метаданных сценария на стороне Engine утверждён; при null он не пишется в JSON.
- Ошибка запуска закрывает сессию, возвращает в главное меню и пишется в InterfaceLog; карта не показывается.
- Отображаемое имя — «Обучение» / Tutorial.

## Допущения

- Ограничения D-03 и D-04 действуют только в бою обучения; обычный бой по F8 не меняется.
- При наличии хотя бы одного сохранения «Новая игра» открывает выбор сценария, как раньше.
- После боя обучения карта работает обычно: сохранение доступно, F8 работает.
- Имена сценариев в `scenario.json` не локализуются и хранятся по-английски, поэтому в файле записано `Tutorial`. Сценарий скрыт и в списке выбора не показывается.

## Приёмка эпика

1. Tutorial отсутствует в списке выбора сценариев, остальные сценарии и их порядок не меняются.
2. «Новая игра» без сохранений открывает бой обучения; карта не становится текущим экраном до завершения боя.
3. В бою обучения Esc ведёт к подтверждению выхода в главное меню, сохранение отклоняется Engine.
4. После завершения боя доступна только кнопка «На карту»; дальше карта работает как обычно.
5. Обычный бой по F8, формат существующих сохранений и сценариев сохранены.
