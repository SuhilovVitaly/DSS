# EP-0023 — интерфейс карточки пилота с командами

Это дополнение к [DesignSpec EP-0019](../EP-0019-tactical-battle-ui-redesign/DesignSpec.md) и UiSpec EP-0020. Всё, что здесь не названо, остаётся как в EP-0019, EP-0020 и EP-0022. Этот документ — единственный источник вида эпика: координаты, размеры шрифтов, цвета, тексты и состояния. Пользователь выбрал вид «вертикальные шкалы, раскрывается только выбранная карточка» (вариант v18, D-01).

Координаты даны в единицах макета 1280×720 (масштаб `S = H/720`; при 1920×1080 — ×1,5). Текст рисуется функцией `T` EP-0019 (`y` — базовая линия), кнопки — `Button`, поля — `BoxText`, строка ловушки — `DecoyRow`, кнопка уклонения — `EvadeButton`, ползунок — `Slider`. Цвета — токены EP-0019/EP-0020: `Text #ECF2F4`, `Muted #9FB3B8`, `Track #2A3337`, `Box #16262A`, `BoxEdge #2A454A`, `ButtonFill #152A2D`, `Cyan #22E3F0`, `Purple #A98BF5`, `Green #6EE08C`, `Yellow #F5C04A`, `YellowDark #3A2F10`, `Orange #FF7A2F`, `Red #FF5A5A`, `PurpleDark #2A2145`, `GreenDark #1E3A26`, `Heat #E05A78`, `Dust #B08CE8`.

Обозначения карточки: `r` — прямоугольник карточки, `r.Left = 6`, `r.Right = 196` (ширина 190); `x0 = r.Left + 6 = 12`, `x1 = r.Right − 6 = 190` (ширина содержимого 178).

## 1. Состав колонки

Колонка содержит одну карточку на каждого своего дрона, в том же порядке, что и сейчас (`PilotCardModel.Project`). Карточка состоит из базовой части высотой 82 (§2) и, только у карточки с `PilotCard.Selected`, блока раскрытия (§3, §5–§7). Команды есть только в блоке раскрытия.

## 4. Раскладка и прокрутка колонки

- **Видимая область:** `6 … 196 × 6 … 714`.
- **Положение карточек:** `top₀ = 6`, `topᵢ₊₁ = topᵢ + hᵢ + 5`, к каждой применяется смещение `−Scroll`. Полная высота `T = Σhᵢ + 5 × (n − 1)`.
- **Без прокрутки.** Если `T ≤ 708`, то `Scroll = 0`; без раскрытия раскладка совпадает с текущей (`6 + 87 × i`), и восемь карточек заканчиваются на 697.
- **С прокруткой.** Если `T > 708`, то `Scroll` лежит в `0 … T − 708`:
  - колесо над видимой областью меняет `Scroll` на `−40 × sign(delta)`;
  - при смене выбранного дрона `Scroll` меняется на минимальную величину, при которой выбранная карточка видна целиком;
  - карточки отсекаются по видимой области, и попадание считается только по видимой части.
- **Индикатор** рисуется только при `T > 708`:
  - дорожка `198 … 200 × 6 … 714`, роль `ui.pilot-card.scroll` (fill), по умолчанию `Track`;
  - бегунок высотой `max(24, 708 × 708 / T)` со смещением `Scroll / (T − 708)` от свободного хода, роль `ui.pilot-card.scroll` (stroke), по умолчанию `Muted`.
- **Подписи на карте.** Зона колонки для подписей — `(0, 0) … (202, низ последней видимой карточки)`.
- **Тестовые прямоугольники.** `Layout.Rects["pilot:<id>"]` — видимый прямоугольник карточки.

Пробы даны в единицах макета на сценах EP-0019/EP-0020: seed 1, бой «Начальный бой», classic, русский язык. Выбор по умолчанию такой же, как в текущем main: в движении хода 1 выбрана Вера, в стрельбе хода 4 — Юн, в результатах хода 4 показан выстрел Марты.
