# Колонка карточек пилотов нового вида

## Входное техническое задание

D-01, D-02. Колонка — `PilotCardColumn.cs:10-13` (шаг 87, высота 82), отрисовка `:14-66`; данные — `PilotCardModel.Project` (`PilotCardModel.cs:40-121`). Прямоугольники колонки используются в `TacticalBattleScreen.Overlay.cs:21-28` (`OverlayRects`, `OverlayHit`), `:36-40` (клик выбирает дрона) и в зоне подписей карты `BattleMapRenderer.cs:98`. Безопасная зона камеры начинается с x = 202 (`TacticalBattleCamera.cs:66`, `BattleMapRenderer.cs:29`).

## User story

Как игрок, я хочу видеть состояние каждого своего пилота по трём вертикальным шкалам и раскрывать карточку выбранного дрона, чтобы управлять им прямо из неё.

## Dependencies

— (база: `main` @ 8b0bf6ce, после EP-0022)

## Completion evidence

- Базовая карточка 190×82 по UiSpec §2 нарисована для каждого своего дрона из тех же полей `PilotCard`, что и сейчас.
- Колонка раскладывается с переменной высотой карточек (раскрыта только выбранная, UiSpec §3) и прокручивается, если не помещается (UiSpec §4).
- Клики по карточке и по её командам, перетаскивание и колесо мыши маршрутизируются через одну раскладку; есть тестовый доступ к границам команд.

## Acceptance criteria

- **US1-AC1.** Нераскрытая карточка занимает `190×82` и рисуется по UiSpec §2: портрет 34, плашка статуса и маркер ловушки справа от портрета, имя и оружие под портретом, три вертикальные шкалы со значением сверху и иконкой снизу, строка фазы. Тексты плашки и строки фазы — из `PilotCard` без изменений смысла; пробы UiSpec §10.1 проходят в фазах движения, стрельбы и результатов.
- **US1-AC2.** Высота карточки равна 82 плюс высота блока раскрытия (UiSpec §3, только у карточки из `PilotCard.Selected`); шаг между карточками 5; восемь нераскрытых карточек заканчиваются на `y = 697`; при суммарной высоте больше 708 колонка прокручивается колесом над ней, выбранная карточка после смены выбора видна целиком, справа рисуется индикатор (UiSpec §4).
- **US1-AC3.** Попадание мышью, `OverlayRects`, зона подписей карты и `Layout.Rects["pilot:<id>"]` берут прямоугольники из одной раскладки текущего кадра с учётом прокрутки; клик по телу карточки выбирает дрона в движении и стрельбе как сейчас; клик по команде выбранной карточки выполняет её; при `Pending` и во время анимации команды не срабатывают.

## Non-goals

Содержимое блоков раскрытия (US-0002…US-0004), изменение правой панели (US-0005), роли скинов (US-0006).

## Invariants

Камера и безопасная зона карты (x ≥ 202) не меняются. Порядок карточек и выбор дрона по умолчанию прежние. Боевые данные, приказы и поток RNG не меняются.
