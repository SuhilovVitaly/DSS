# Проверка EP-0035 после грумминга

Дата: 2026-11-17. Область: полный эпик, истории, тикеты, зависимости и соответствие решениям пользователя. Это проверка и исправление плана, не реализация и не приёмка игры.

## Исправленные несогласованности

| Проблема | Исправление и владелец |
|---|---|
| В исполняемых шагах оставались два состава по 2–3 дрона | US0001: четыре группы; 45/45/10; Логово 6, Танкред 10, эскадра 12. Сюжетное появление капитана исключено из EP-0035. |
| Старые gaps и формулировки доклада расходились с решениями | US0009–0011: Ирина 264 км, скрипт 192 км; погрешности ±1/±2 и ±2/±4; одно приблизительное число и тип корабля; один batch за шаг и один автоматический доклад на группу за кампанию. |
| Перехват мог случиться до первого обнаружения игроком, оставляя состав боя не определённым | US0011/0016: состав материализуется один раз до durable prebattle checkpoint; скрытый состав не раскрывается через fog/debug. |
| После Timeout/Draw с живыми носителями судьба группы оставалась открытой | Пользователь принял D-35-50: участвовавшая группа удаляется с карты после завершённого боя. US0003/0004/0015/0016 сохраняют actual damage и exactly-once retirement; незавершённый бой восстанавливается с начала. |
| Формально существующие зависимости не покрывали все требуемые API и реальные точки подключения | Исправлены prerequisites и allowlists; отдельная интеграционная история подключает подготовку команд, валидацию и simulation tick к существующим владельцам. |
| Старые таблицы выдавались за актуальный полный план | Текущая карта в Documentation строится по полному набору историй; старые карты явно помечены историческими. |

## Ограничения проверки

Структурная проверка после исправлений: 17 историй, 66 тикетов, 85 Markdown-файлов эпика. Все 66 узлов тикетного графа топологически разрешены; неизвестных prerequisite ID и циклов нет. Проверены совпадение ID с путями/frontmatter, локальные ссылки, максимум 5 тикетов на историю, заявленные allowlists (1–5 файлов, совпадают со списками), layer metadata и whitespace. Git diff --check для Board прошёл. Эти результаты относятся только к документам.

Баланс, удобство диалога, native UI, реальные сохранения и интеграция с итоговым EP-0034 требуют проверки при реализации. Нынешний аудит не запускает build/tests и не меняет production. Технические параметры модуля, геометрия патруля и возможный drift схем проверяются owning tickets; утверждённые радиусы, вероятности и правила заново согласовывать не требуется.
