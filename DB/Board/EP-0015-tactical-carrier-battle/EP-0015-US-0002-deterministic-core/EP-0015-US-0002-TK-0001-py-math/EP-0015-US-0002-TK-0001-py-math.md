## Implementation assumptions before editing — 2026-11-05

PyMath uses Spec/Combat §1 clamp branch order directly (not min(max())). Min/Max replace the candidate only on strict comparison; equality, signed zero and unordered NaN retain the first value. FloorNonNeg returns a double floor and rejects negative/nonfinite input; consumers narrow to bounded integer types explicitly. Fmod is C# floating remainder for finite inputs.

The source guard is deliberately conservative: every division in TacticalBattle production code must visibly use a double literal or an adjacent `(double)` cast. This prevents int/int including integer variables without introducing compiler packages or guessing types from identifiers. It can reject an already-double variable expression; express the cast explicitly. The scanner strips comments/strings, reports path+line and has positive/negative self-tests. Stable LINQ OrderBy is allowed; in-place Sort, unordered unique operations and specified numeric/format calls are forbidden.
