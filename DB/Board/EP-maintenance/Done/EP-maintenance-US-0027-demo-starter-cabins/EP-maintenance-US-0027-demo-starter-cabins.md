# Жилые модули стартового демо-носителя

На новом демо-носителе два четырёхместных жилых модуля. Семь кают занимает стартовый экипаж, одна доступна для пассажира или пленника. Первая пассажирская заявка учитывает фактическую вместимость. Загрузка использует установленные модули из сохранения.
