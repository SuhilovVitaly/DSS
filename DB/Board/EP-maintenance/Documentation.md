# Исправления и доделки

Постоянный эпик для исправления багов, устранения регрессий и небольших доделок DSS. Новые истории и тикеты добавляются по мере появления задач.

## Структура

- Активная история хранится в `EP-maintenance-US-<NNNN>-<slug>/`, активные тикеты лежат в её подпапках.
- Каждый выполненный тикет переноси в `Done/<папка истории>/<папка тикета>/` сразу после завершения. Если в истории ещё есть работа, её документ остаётся в активной части эпика.
- После завершения всей истории перенеси её документ и остальные материалы в `Done/<папка истории>/`. При переносе сохраняй имена, ID и обновляй ссылки. При продолжении работы ищи существующий тикет также в `Done/`.

Номера историй выделяются внутри эпика, номера тикетов — внутри истории. Истории группируют связанные задачи по результату. Каждое исправление или доделка получает отдельный тикет. Если работа связана с задачей номерного эпика, укажи ссылку на неё в тикете.
