# Новая игра на пустом носителе

## Входное техническое задание

Подготовить кампанию с пустым носителем, достаточным стартовым бюджетом и четырьмя дронами из действующего боя. Для каждого дрона нужен ангар, а для пилотов нужны каюты. Результат этой истории входит в путь закупки и боевого использования из [описания эпика](../Documentation.md).

## User story

Как новый игрок, я получаю пустой носитель с рабочим двигателем и стартовыми Tokens. Я начинаю у верфи, чтобы сразу купить первый модуль. На корпусе есть место для четырёх отдельных ангаров и жилья для четырёх пилотов.

## Grounding

`Scenarios/Default/scenario.json:10–11,29–198` задаёт 2 000 Tokens и оснащённый старт. `Scenarios/Docked/scenario.json:16–30` показывает действующий формат начальной стыковки.

## Acceptance criteria

- **AC-01.** Обычная New Game запускается с единственным установленным двигателем, пустым крылом, без нанятых пилотов, с топливом и заданным бюджетом.
- **AC-02.** Первый визит действителен сразу. После покупки мостика игрок может отплыть и состыковаться со второй станцией. На корпусе помещается весь комплект.

## Non-goals

Ограничить работу результатами этой истории и allowlist её тикетов. Общий backlog, включая расширенный найм, трофеи и сохранение внутри боя, ведётся в эпике.

## Dependencies

US-0009. Порядок реализации определяется зависимостями конкретных тикетов.

## Invariants

Торговля, размещение и учёт состояния авторитетны в Engine. Отказ и повтор операции сохраняют деньги и имущество в согласованном состоянии. Для действующих входов, старых сохранений и F8 проверяются существующие контракты в пределах этой истории.
