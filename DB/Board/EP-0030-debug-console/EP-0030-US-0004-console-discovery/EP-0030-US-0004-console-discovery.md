# US-0004 — Справочные команды консоли

## Входное техническое задание

D-06 [эпика](../Documentation.md). Пользователь запросил тикеты для `list_units` и `help`, причём `help` показывает все команды консоли. Точное сообщение сохранено в source_request; время выше — время записи, не отправки.

## User story

Как оператор, я хочу вызвать `help`, чтобы увидеть все команды консоли, их синтаксис и назначение. Команды, неприменимые на текущем экране, остаются в справке с указанием области применения. В бою я вызываю `list_units`, чтобы увидеть всех участников обеих сторон, их идентификаторы и состояние. Обе команды только читают данные и не меняют бой, паузу, ресурсы или текущий экран.

## Grounding

- `src/DeepSpaceSaga.Contracts/TacticalBattleSnapshot.cs:151` — снимок содержит BattleId, Revision, Phase, Turn, PlayerSide и Units.
- `src/DeepSpaceSaga.Contracts/TacticalBattleSnapshot.cs:51` — юнит содержит Id, Side, Kind, Hull, MaxHull, State и Build; `:36` — Build содержит PilotName. Имя пилота не является отдельным доказанным именем юнита.
- `src/DeepSpaceSaga.Contracts/TacticalBattleSnapshot.cs:7` — текущие виды Drone и Carrier; отдельного enum Tug нет. Список не должен фильтровать предполагаемые «тэги»: выводятся все Units.
- `src/DeepSpaceSaga.Client/GameSessionHandle.TacticalBattle.cs:21` — существующий `GetTacticalBattleStateAsync(CancellationToken)` позволяет прочитать снимок через сессию; null не позволяет надёжно различить отсутствие боя и ошибку получения.
- Файлы DebugConsole создаёт US-0001 (TK-0002: `DebugCommand.cs`, `DebugCommandRegistry.cs`, `DebugConsoleController.cs`; TK-0003: `DebugCommandCatalog.cs`, overlay). US-0001 исполняется в той же ветке раньше US-0004; единственная точка регистрации команд — `DebugCommandCatalog.CreateDefault()`.

## Acceptance criteria

- **AC-01:** `help` без аргументов выводит каждую зарегистрированную команду ровно один раз: имя, синтаксис, описание и область применения. В итоговом эпике присутствуют `help`, `list_units`, `exit_battle`, `kill_drone name`.
- **AC-02:** `help` работает без игровой сессии и не скрывает команды, недоступные на текущем экране. Новая зарегистрированная команда автоматически попадает в справку.
- **AC-03:** `list_units` без аргументов выводит все Units текущего снимка, включая обе стороны, носителей и уничтоженные/отключённые объекты. Строка содержит Unit ID, отдельное имя пилота (если есть), сторону, тип, состояние и Hull/MaxHull. Заголовок содержит BattleId, Revision, ход и фазу; сортировка Side, затем Id (Ordinal).
- **AC-04:** при отсутствии сессии выводится «Нет активной сессии»; при null-снимке — «Нет активного боя или данные недоступны». Пустой Units — «Участников нет». После смены сессии/боя устаревший список не публикуется как текущий; при ошибке запроса не показываются старые данные как новые.
- **AC-05:** обе команды не меняют мир/бой/скорость и не запускают игровые команды. Лишние аргументы отклоняются с синтаксисом. Длинный вывод полностью доступен через прокрутку оболочки.
