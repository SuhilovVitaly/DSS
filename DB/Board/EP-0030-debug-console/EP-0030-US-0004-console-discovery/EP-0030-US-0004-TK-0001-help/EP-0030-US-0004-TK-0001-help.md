# TK-0001 — Команда help

## Why

Оператор должен видеть полный набор команд и синтаксис без обращения к документации. Покрывает AC-01/02/05 [истории](../EP-0030-US-0004-console-discovery.md).

## Decisions

Пользователь: «`list_units`  help - показывает все команды дебага консоли - добавь тикеты на оба». Записано 2026-11-16T06:21:45Z. Запрошены документы тикетов, не реализация.

## Assumptions

`help` без аргументов; сортировка команд Ordinal по имени, одна запись на команду. Выводит имя, синтаксис, описание, область применения; контекстная недоступность не исключает строку. Область и описание — метаданные реестра, не отдельная вручную поддерживаемая таблица. Новая команда автоматически появляется после регистрации. Нереализованные команды не регистрировать как работающие заглушки.

## Public API after the change

Игровые/transport API не меняются. Проектируемая внутренняя client-граница: `DebugCommandDescriptor(string Name, string Syntax, string Description, string Scope)` и `DebugCommandRegistry.DescribeAll(): IReadOnlyList<DebugCommandDescriptor>`. Дескриптор связан с зарегистрированным обработчиком; имена уникальны, сравнение Ordinal. Проектируемый `HelpDebugCommand.Execute(DebugCommandRegistry registry, string arguments): IReadOnlyList<string>` возвращает строки для штатного вывода. Это новые сигнатуры, не утверждение об имеющемся коде. При иной реализации зависимости сначала синхронизировать Board, не создавать второй реестр.

## Implementation steps

1. Проверить готовность US-0001 и единого реестра/вывода. Не реализовывать UI оболочки в этом тикете.
2. Обеспечить перечисление метаданных реальных обработчиков и зарегистрировать help, включая саму help в вывод.
