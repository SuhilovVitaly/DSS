## Why

Оператор должен видеть полный набор команд и синтаксис без обращения к документации. Покрывает AC-01/02/05 [истории](../EP-0030-US-0004-console-discovery.md).

## Assumptions

`help` без аргументов; сортировка команд Ordinal по имени, одна запись на команду. Выводит имя, синтаксис, описание, область применения; контекстная недоступность не исключает строку. Область и описание — метаданные реестра, не отдельная вручную поддерживаемая таблица. Новая команда автоматически появляется после регистрации. Нереализованные команды не регистрировать как работающие заглушки.

## Public API after the change

Игровые/transport API не меняются. `HelpDebugCommand : IDebugCommand`:

```csharp
DebugCommandDescriptor Descriptor => new("help", "help", "Показать все команды консоли", "везде");
```
