## Правила quoted execution
unitPrice = ComputeUnitPriceCredits(base, ResolveStationPriceFactors(...)); unitPrice<1 → disabled `unknown_item_type`.

GetTradeQuote — Max без учёта requested: Buy min(stock, PlayerCredits/price, freeCargoKg/UnitMassKg при mass>0); Refuel min(stock, PlayerCredits/price, свободный tank кг); Sell min(cargoQty, purse/price, room) (purse = Budget bounded / station Credits legacy; room = MaxStock−stock только bounded Cargo, иначе без ограничения).
- Buy/Refuel: qty≤Max → Executable=qty; иначе disabled с первым ограничителем: insufficient_player_credits, insufficient_station_stock, cargo_capacity_exceeded/fuel_capacity_exceeded.
- Sell: qty>cargo → disabled insufficient_cargo_quantity; Executable=min(qty, budgetCap, roomCap); LimitReasons = [station_budget_exceeded если ограничил budget, station_capacity_exceeded если ограничил room]; Executable=0 → disabled с первым из них.
- Total = checked(Executable*price); overflow → disabled value_overflow. Curve=[(Executable, price)]. Overflow PlayerCredits+proceeds / station Credits+cost при выдаче не проверяются — их ловит preflight.

Execute: (1) резолвер + Fuel guard; (2) TryValidateTradeQuote; (3) целостность: ΣCurve.Quantity=Executable, checked Σq·p=Total, Executable≤Requested, Buy/Refuel Executable=Requested, Sell partial только при непустых LimitReasons, иначе invalid_quote; (4) повторная checked-проверка ресурсов (шаг 5 тикета); (5) stage updatedShip/updatedStation (Inventory, Credits±, Budget, MarketRevision=next) + newPlayerCredits; (6) receipt; (7) commit `_objects[ship]`, `_objects[station]`, `PlayerCredits`; (8) `RecordCommandResult(Executed, executedQuantity: partial ? actual : null, tradeReceipt)`; (9) удалить quote из cache.
Rejected receipt: (knownStationId, raw ItemTypeId, raw QuoteId, raw MarketRevision, known current revision или null, raw Quantity, 0, 0, []). Rejected quote не расходуется.

## Отклонения от тикета (утверждены)
1. Свой seam вместо US-0015; DTO и GetTradeQuote internal; нет PriceReasons/RequestId idempotency; curve один сегмент.

5. Не-trade изменения рынка ловит fingerprint QuoteContext.
6. LimitReasons/коды = station_budget_exceeded/station_capacity_exceeded.
7. Issuer не проверяет overflow зачисления; ловит preflight → value_overflow.
8. Legacy success тоже увеличивает revision; receipt у legacy нет.
