# Оформление меню и профиля

## Основание и зависимости

[Родительская история](../EP-0026-US-0002-menus-and-sessions.md) определяет зависимости и пользовательский результат. [Эпик](../../Documentation.md) определяет визуальный контракт.

## Code context

Область реализации — UI/Screens/MainMenu, GameMenu, Settings, ScenarioSelect, Load, Save, ShipDestroyed; TacticalBattleSkinPreference.

## Критерии приёмки

Оформить меню и слоты, проверить ошибки и длинные подписи. Tabletop используется при первом запуске при наличии пакета, явный выбор боя сохраняется. Проверить применимые состояния из родительской истории.

## Проверка

Зафиксировать фактические проверки, review и открытые условия приёмки перед отдельным коммитом.
