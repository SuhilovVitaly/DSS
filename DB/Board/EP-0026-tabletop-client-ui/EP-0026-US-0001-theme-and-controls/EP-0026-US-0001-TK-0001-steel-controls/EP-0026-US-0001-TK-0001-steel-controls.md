# Общие элементы Tabletop

## Основание и зависимости

[Родительская история](../EP-0026-US-0001-theme-and-controls.md) определяет зависимости и пользовательский результат. [Эпик](../../Documentation.md) определяет визуальный контракт.

## Code context

Область реализации — UI/Controls, растровые тесты Client.

## Критерии приёмки

Стальная плита, утопленное поле и кнопка имеют общий скос и семантические состояния. Существующие прямоугольники ввода остаются источником геометрии. Проверить применимые состояния из родительской истории.

## Проверка

Зафиксировать фактические проверки, review и открытые условия приёмки перед отдельным коммитом.
