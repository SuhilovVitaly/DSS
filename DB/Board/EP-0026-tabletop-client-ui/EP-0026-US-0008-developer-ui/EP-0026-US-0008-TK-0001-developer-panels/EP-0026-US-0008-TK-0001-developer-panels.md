## Code context

## Критерии приёмки

Оформить диагностику и мастерскую, проверить поля, скролл и ошибки ввода. Проверить применимые состояния из родительской истории.

## Проверка

Зафиксировать фактические проверки, review и открытые условия приёмки перед отдельным коммитом.
