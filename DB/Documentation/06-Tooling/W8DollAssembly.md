# Как собрать куклу W8 в сторонней программе

Для одного кадра нужны PNG тела выбранной позы и одна прямоугольная ячейка из атласа головы. Помести тело в `(0, 0)`, подготовь стык по правилам позы ниже и положи ячейку поверх тела. Это можно сделать в растровом редакторе, скрипте или игровом движке.

## Сначала выбери комплект

**Основной W8** находится в `src/DeepSpaceSaga.Client/Images/Persons/W8`. Для любого его персонажа и костюма в стойке применяй таблицу шва ниже, включая SN7L4D на игровом SATIN.

**Отдельный пилот SN7L4D** содержит только стойку, два тела с продлённой шеей и свой `threequarter.png`. Все входные файлы возьми из одного пилотного корня. Для GREEN используй `Templates/skin-mask-green.png`, для SATIN — `Templates/skin-mask-satin.png` рядом с телами. Примени `skinTone` к целому телу по яркости L / 255 и наложи ячейку головы в исходном цвете в **(69, 0)**. Пропусти операцию вырезания верхней шеи. Размеры, ячейки эмоций и экспорт одинаковы для обоих комплектов. Имена файлов и точка вставки сами по себе не определяют версию. [Правила цвета](ThreeQuarterCharacterSkinTone.md)

## Файлы и координаты

Пути в таблице отсчитываются от [каталога W8](../../../src/DeepSpaceSaga.Client/Images/Persons/W8). Имя каталога персонажа строчное, например `ka4v7n`. ID костюма записан заглавными буквами, например `SATIN`. Для смены позы выбери соответствующие ей тело и атлас.

| Поза | Тело и размер холста | Атлас головы | Размер ячейки | Куда поставить верхний левый угол ячейки |
|---|---|---|---|---|
| Три четверти | `Clothes/ThreeQuarterOutfit/<ID>.png`, 282×747 | `Portraits/<id>/threequarter.png`, 720×190 | 144×190 | **(69, 0)** |
| Пленный | `Clothes/Prisoner/<ID>.png`, 416×747 | `Portraits/<id>/prisoner.png`, 680×144 | 136×144 | **(48, 416)** |

Все координаты ниже в пикселях от **верхнего левого угла**, с нуля. X растёт вправо, Y вниз. Вырезай **всю ячейку с прозрачными полями** и задай привязку к её верхнему левому углу. Если программа автоматически обрезала прозрачность слева на `dx` и сверху на `dy`, прибавь `(dx, dy)` к точке вставки. Для программы с началом координат снизу слева и привязкой к **нижнему левому углу полной ячейки** точки вставки равны `(69, 557)` и `(48, 187)` соответственно.

## Выбор эмоции

Ячейки лежат в одну строку. Выдели прямоугольник с указанного X и с Y = 0, шириной и высотой из таблицы выше. Положение ячейки на теле одинаково для всех пяти эмоций и всех костюмов одной позы.

| Левый край ячейки в атласе | neutral | pain | anger | joy | pleasure |
|---|---:|---:|---:|---:|---:|
| Три четверти, X | 0 | 144 | 288 | 432 | 576 |
| Пленный, X | 0 | 136 | 272 | 408 | 544 |

## Три четверти основного W8 · точная линия стыка

Верх общей шеи уже нарисован в ячейке головы. Открой **копию** тела и добавь к ней белую маску слоя. В каждом диапазоне X из таблицы скрой на маске прямоугольник от Y = 0 **до Y₀ − 1 включительно**. В редакторе используй выделение по пикселям с растушёвкой 0. В скрипте эквивалентная операция — присвоить RGBA = 0 этим пикселям копии тела. Строка Y₀ остаётся на теле. Все границы X в таблице включительные.

| X на теле | Y₀, первая сохранённая строка тела |
|---|---:|
| 129–130 | 109 |
| 131 | 110 |
| 132 | 109 |
| 133 | 111 |
| 134 | 112 |
| 135–138 | 113 |
| 139 | 114 |
| 140–141 | 115 |
| 142–143 | 116 |
| 144–148 | 117 |
| 149–155 | 119 |

За пределами X = 129…155 тело сохраняется целиком. Положи ячейку в **(69, 0)**. Для проверки на X = 129 последний пиксель перед швом находится на Y = 108, первая строка тела — 109. На X = 155 эта пара — 118 и 119. При автоматизации читай те же значения из `neckSeam.firstBodyPixelYByColumn[x - startX]` при `bodyHasFullNeck = true`. ## Пленный · точное перекрытие под подбородком

Оставь тело целиком. Положи ячейку в **(48, 416)**. Стык образует альфа уже нарисованной головы. Опоры верхнего среза шеи — **(130, 484)** спереди и **(151, 475)** сзади на теле. Внутри ячейки им соответствуют **(82, 68)** и **(103, 59)**. Именованный ориентир `landmarks.neckSeam` находится ниже, в **(140, 514)** на теле, или **(92, 98)** внутри ячейки. Все три точки совмещаются одним размещением. [Манифест пленного](../../../src/DeepSpaceSaga.Client/Images/Persons/W8/Clothes/Prisoner/Templates/pose.json)

| 476 | 140–146 |

| 478 | 135–140 |

Для автоматической проверки выбери X от 130 до 151 и пиксели в пределах четырёх строк по вертикали от прямой между опорами. Оставь пересечение с `neckProtect > 0` и `portraitAlpha == 255` в координатах тела. Альфу головы в точке `(x, y)` проверяй по ячейке в `(x − 48, y − 416)`. ## Цвет и экспорт

Для совпадения цвета кожи прочитай `Portraits/<id>/settings.json → skinTone`. До наложения головы затонируй открытую кожу тела по маске **этого костюма и позы**. Базовый тон стойки — `#DA9C77`, пленного — `#C18A69`. У SATIN своя маска в каждой позе. Для точного цвета верхней шеи **основной** стойки нужен подготовленный под этот тон атлас либо исходные слои для расчёта вклада шеи под волосами. Голову пленного накладывай в цветах атласа. [Выбор маски, формула тонирования и исходные слои](ThreeQuarterCharacterSkinTone.md)

Собирай при 100% масштабе и непрозрачности слоёв, режим наложения **Normal / source-over**. Используй straight alpha для PNG; у полупрозрачных пикселей сохраняй собственный RGB слоя. Сохрани один кадр в PNG RGBA8 sRGB с прозрачным фоном и исходными размерами холста. Увеличивать или уменьшать можно уже собранную куклу целиком.

**Пример для KA4V7N, SATIN, joy.** В стойке вырежи из атласа прямоугольник `(432, 0, 144, 190)` и поставь в `(69, 0)` на подготовленное тело SATIN. У пленного вырежи `(408, 0, 136, 144)` и поставь в `(48, 416)` на полное тело SATIN этой позы. Формат обоих прямоугольников — `(x, y, ширина, высота)`.
