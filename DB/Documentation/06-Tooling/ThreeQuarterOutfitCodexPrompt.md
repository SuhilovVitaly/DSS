# Промпт Codex для нового костюма W8 в двух позах

Скопируй всё ниже линии. Подставь ID костюма и описание. Костюм использует ту же фигуру и точку крепления головы, что и первый костюм GREEN. Рисунок одежды можно менять в разрешённой области. Посадка общих портретов обеспечивается попиксельным сохранением базовой геометрии.

## Параметры

- ID костюма — новый ключ из заглавных букв `A–Z`, например `UTILITY`. До генерации проверь, что ID свободен в обоих словарях `outfits`, обоих клиентских каталогах, обоих путях именных масок и по пути `work/outfit/<ID>.uncut.png`. При занятом ID сохрани существующие файлы и записи.
- Описание — назначение костюма, цвета, материалы и детали. Для комбинезона с посадкой GREEN действуют его контур и область ткани. Для модели с иным кроем (как SATIN) используй ветвь открытого костюма ниже.
- По умолчанию готовь новый рисунок одежды. Если запрошена только расцветка, примени перекраску из шага 3.

## Художественный стиль костюма

Для стойки и пленного используй [Portraits-Master](../../../src/DeepSpaceSaga.Client/Images/Persons/W8/Portraits-Master) как источник рисовки. Выбери из текущего содержимого папки образец, на котором видны ткань и фурнитура. Приложи его целиком или возьми фрагмент с одеждой с пометкой `STYLE ONLY`. Образец показывает контур швов, тени в складках, блики на коже и металле, количество деталей на карманах и застёжках в игровом масштабе. Крой, цвет и материалы бери из заказа. Позу, силуэт и стык шеи определяют подложка соответствующей позы и её шаблон.

Проверь кисти, колени, стопы и просвет между руками.

Проверь тонирование на исходном и контрастном тоне. Зарегистрируй маску стойки от корня W8, маску пленного относительно его `Templates`, обе в `masks.skinByOutfit[ID]`.

## Шаг 1. Зафиксируй базу и области правки

1. Перечитай GREEN и зафиксируй контрольные суммы базового PNG, подложки, масок, направляющих и существующих костюмов. Сохрани исходное состояние `pose.json` для сравнения полей. Используй снимки и промежуточные файлы только в `D:/DeepSpaceSaga/artifacts/validation/<task>/<run>/`.
2. Построй прямоугольник портрета `R` из `drawOrigin` и `cellSize`. В текущей позе это x 69–212, y 0–189 включительно на холсте 282 × 747. В этой области лежит стык шеи и перекрытие плеч волосами.
3. Вычисли допустимую ткань `F = (baseAlpha == 255) ∧ (fabricMaskAlpha > 0) ∧ (skinMaskAlpha == 0)`. Для нового рисунка разрешённая область `E = F ∧ ¬R`. При необходимости сузь её до нужных панелей одежды. Для перекраски используй только `F`.
4. Поза, геометрия выреза, ворот у шеи, линия стыка с портретом и альфа тела сохраняются из GREEN. Существующие портреты, их настройки и остальную геометрию манифеста сохрани побайтно или, для `pose.json`, по значениям полей.

## Шаг 3. Собери итоговый PNG из точной копии GREEN

1. Начни с копии рабочей подложки `work/outfit/GREEN.uncut.png`. Для нового рисунка перенеси только RGB из разрешённой области `E`. Для плавного перехода по краям используй вес маски ткани, обнулённый за пределами `E`. В зоне портрета `R` остаётся исходный RGBA.
2. Для заказанной перекраски вычисли RGB из исходных пикселей GREEN, сохраняя объём и тени. Применяй цвет по маске `F`, в том числе на её непрозрачной ткани внутри `R`, если это нужно для единой расцветки. Геометрия воротника сохраняется, а кожа, прозрачность и сглаженные края остаются исходными. Для серого цвета возьми за основу `gray_variant` в `tools/build_pilot.py` и примени разрешённую маску.
3. Сохрани кандидата как RGBA8 sRGB со straight alpha и исходным размером холста. Сохрани шею целиком от воротника до верхней кромки вместе с цветом кожи и сглаживанием GREEN. Линию neckSeam использует только компоновщик при наложении портрета.

Фиксация сглаженного края важна для задних прядей. В существующих атласах `visible_back_hair` уже учитывает перекрытие базовым телом и смешивание на его полупрозрачных краях. Сохранение альфы и RGBA этих краёв гарантирует совместимость с теми же атласами.

## Шаг 4. Проверки перед добавлением

Перечитай сохранённый PNG и сравни с исходным GREEN по координатам пикселей.

**Ровный тон шеи в стойке.** Осмотри открытый участок от линии челюсти до воротника или ключиц при 1:1 на сборке с базовым и контрастным `skinTone`. Слева и справа должен читаться один оттенок кожи с мягкой разницей освещённости. Цветные пятна, светлая полоса вдоль края или скачок тона на стыке требуют исправления. В новом рисунке выровняй полутон по соседней коже эталонной шеи, сохрани естественную тень под челюстью. Защищённые пиксели GREEN переноси по правилам шага 3.

| Проверка | Условие выпуска |
|---|---|
| Формат и контур | Режим RGBA8, размер из `pose.json`, альфа совпадает пиксель в пиксель по всему холсту |
| Кожа и шов | RGBA во всех пикселях маски кожи совпадает. От верхней кромки шеи до воротника цвет и альфа совпадают с цельным GREEN, включая пиксели выше линии стыка |
| Сглаженные края | RGBA каждого пикселя GREEN с альфой от 1 до 254 совпадает |
| Область портрета | Для нового рисунка все RGBA в `R` совпадают. Для перекраски изменения в `R` совпадают с расчётной перекраской GREEN по `F` |
| Разрешённая область | Все изменённые RGB находятся в `E` для нового рисунка или `F` для перекраски. За пределами разрешённой области RGBA совпадает |

Проверь точное равенство массивов. В отчёте об ошибке укажи первую координату, число отличающихся пикселей и ожидаемый слой. Если проверка выявила изменение защищённой области, восстанови её из GREEN и повтори проверку сохранённого файла.

В изолированной копии конфигурации добавь путь временного кандидата в `outfits` и укажи в `portraitAtlas` абсолютный шаблон `<временный корень портретов>/{id}/threequarter.png`. Скопируй в конфигурацию направляющую по пути `neckSeam.bodyGuide` и сохрани `neckSeam.bodyHasFullNeck = true`. Запусти `tools/dss3q.py validate --pose <временная папка позы> --outfit <ID> --character VL8H3A`. Эта команда сверяет верх шеи с направляющей и проверяет непрозрачность строки стыка. Вызови `dss3q.compose_image` с той же временной позой, `VL8H3A`, новым ID и каждой эмоцией из `expressions`. Компоновщик читает `threequarter.png` (720 × 190) и накладывает ячейку 144 × 190 в (69, 0) с учётом цельной шеи тела. Проверь наружный контур под ухом и открытый ворот на готовых кадрах. Таблица выше задаёт проверки формы GREEN; для открытого кроя проверь его индивидуальную маску и защищённый стык.

Осмотри стойку в масштабе 1:1 рядом с образцом из `Portraits-Master`. Сравни толщину контура, свет на складках и детализацию застёжек. При совпадении формы GREEN проверки геометрии дополняют визуальную примерку VL8H3A. У открытого кроя проверь также перекрытие прядей, контур шеи и границу ткани на доступных игровых атласах. Для иного кроя выполни проверки открытого костюма выше. Точка стыковки остаётся общей.

На сохранённой стойке при 1:1 проверь, читается ли переход от грудной клетки через талию к бёдрам. В приталенной одежде его показывают крой и натяжение ткани, в свободной — посадка пояса и крупные складки. Толщина и жёсткость материала должны оставаться убедительными.

## Шаг 5. Перенеси дизайн на готовый шаблон пленного

Эталоны и проверочные маски бери из [производственного шаблона](../../../../DSS-Images/Characters/W8/Antropik/prisoner/Templates/template.json). Каждый путь отсчитывай от файла JSON, в котором он записан. Для геометрии используй `referenceBody` производственного шаблона и [BODY-GUIDE.png](../../../../DSS-Images/Characters/W8/Antropik/prisoner/Templates/BODY-GUIDE.png). Холст 416 × 747. Правое плечо персонажа находится слева на изображении и уже дорисовано в GREEN.
2. Для нового рисунка передай ImageGen тело пленного как основу позы и готового стоящего кандидата как образец дизайна и изображение из `Portraits-Master` с пометкой `STYLE ONLY` для рисовки ткани и фурнитуры. Повтори материалы, цвета, панели, застёжки и отделку на согнутом теле. Сохрани положение шеи, ворота, обоих плеч, локтей, кистей, коленей и стоп по шаблону. Для одной расцветки используй тот же рецепт цвета и тени исходного тела пленного.
3. Начни с копии `referenceBody`. В координатах пленного выдели ткань по его собственному рисунку. Переноси новый RGB только внутрь непрозрачной ткани с нулём в масках `masks.skin` и `masks.neckProtect`. Маски шаблона читай как одноканальные изображения L. Сохрани исходную альфу по всему холсту, исходный RGBA кожи, зоны шеи и сглаженных краёв. В зоне `masks.allowedRightShoulderFill` можно менять рисунок ткани с сохранением заполнения и контура восстановленного плеча. Сохрани кандидата как RGBA8 со straight alpha.

Для нового рисунка в позе пленного включи в запрос следующий блок. Ориентиры таза и опоры бери из `landmarks` игрового манифеста.

## Шаг 6. Проверь пленного по сохранённым PNG

- Рядом со стойкой посмотри на тело пленного при 1:1. Со стороны видимого бедра должен читаться округлый объём ягодицы, с плавным переходом от поясницы сверху и в заднюю поверхность бедра снизу. Проверь, что форма различима по крупным светотеневым плоскостям даже на участке без кармана или шва. Сверь `waist`, `hipRight`, `hipLeft`, колени и опору с шаблоном: усиление объёма должно сохранять наклон таза и позу.
- Перечитай кандидата и сверь его размеры и альфу с альфа-каналом `referenceBody` для комбинезона базовой формы. Отдельно сравни альфу с этим эталоном на каждом ненулевом пикселе `masks.allowedRightShoulderFill`. Контроль плеча выполняй на теле без головы, включая переход в рукав и просвет между руками.
- На каждом ненулевом пикселе `masks.neckProtect` и `masks.skin` сравни все четыре канала кандидата с `referenceBody` до коррекции `skinTone`. Допуск для шеи, кожи и альфы плеча — ноль. При расхождении укажи маску, координату первого пикселя и число отличий. Исправь кандидата и повтори проверку.
- Для примерки загрузи `vl8h3a/prisoner.png` и `settings.json` из извлечённого архива. Этот атлас служит источником головы и для нейтральной подложки. Разрежь его на пять ячеек 136 × 144 слева направо по `expressions`. Для каждой ячейки положи её на прозрачный холст в `portrait.drawOrigin` (48, 416). На 60 контрольных пикселях верхнего среза альфа головы должна быть 255. Проверь пересечение `neckProtect > 0` и `portraitAlpha == 255` в полосе ±4 строки между `upperNeckFront` и `upperNeckBack`. Остальной контур принадлежит конкретной голове. [Координаты по строкам](W8DollAssembly.md)
- Наложи каждую ячейку поверх кандидата в той же точке в масштабе 1:1. Проверь сопряжение с воротником, оттенок открытой кожи по [контракту skinTone](ThreeQuarterCharacterSkinTone.md) и форму правого плеча на собранных кадрах. Сверь рисовку ткани и фурнитуры пленного с тем же образцом из `Portraits-Master` в масштабе 1:1. Для всех пяти эмоций используй один и тот же PNG тела и одну точку вставки.

## Шаг 7. Опубликуй проверенную пару

1. Подготовь два PNG тела, две именные маски кожи и копии обоих манифестов во временном каталоге запуска. В каждом словаре `outfits` добавь один и тот же ID с путём из таблицы. Приступай к публикации после успешных проверок обеих поз и десяти сборок VL8H3A. Для открытого кроя также заверши проверки с игровыми атласами.
2. Сохрани цельную стойку в `work/outfit/<ID>.uncut.png`, скопируй её побайтно в `Clothes/ThreeQuarterOutfit/<ID>.png`. Запиши проверенное тело пленного в `Clothes/Prisoner/<ID>.png`. Сохрани индивидуальные маски в каталогах `Templates` соответствующих поз. Обнови оба манифеста. При ошибке восстанови обе регистрации из снимков и убери файлы этого выпуска.
3. Перечитай оба манифеста. Для стойки разреши путь через `Pose.outfit_path(<ID>)`, для пленного — относительно `Prisoner/Templates`. Оба пути должны вести к соответствующим клиентским PNG из таблицы. Сверь SHA-256 опубликованных файлов с проверенными кандидатами, равенство стоящей пары рабочий/клиентский PNG и сохранность эталонов. Сравни каждый манифест с исходным по значениям полей: допустимы только записи нового ID в `outfits` и `masks.skinByOutfit`. В обоих манифестах обязательны отдельные записи масок нового ID. Перечитай зарегистрированные маски и сверь с проверенными файлами.
4. Удали временные проверочные файлы текущего запуска. В ответе укажи ID, оба клиентских пути и результаты проверок шеи и правого плеча. Лист сборок прикладывай по запросу. Коммит выполняй по запросу.
