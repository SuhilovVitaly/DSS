# Промпт Codex для нового костюма W8 в три четверти

Скопируй всё ниже линии. Подставь ID костюма и описание. Костюм использует ту же фигуру и точку крепления головы, что и первый костюм GREEN. Рисунок одежды можно менять в разрешённой области. Посадка общих портретов обеспечивается попиксельным сохранением базовой геометрии.

---

Поза пленного использует [свой шаблон](../../../src/DeepSpaceSaga.Client/Images/Persons/W8/Clothes/Prisoner/Templates/README.md). Для неё бери холст 416 × 747, ориентиры, маску шеи и область восстановления правого плеча из этого шаблона.

## Параметры

- ID костюма — новый ключ из заглавных букв `A–Z`, например `UTILITY`. Проверь, что ключ свободен в `pose.json → outfits` и в клиентском каталоге костюмов ещё нет файла `<ID>.png`.
- Описание — назначение костюма, цвета, материалы и детали. Изменения должны помещаться внутри контура GREEN.
- По умолчанию готовь новый рисунок одежды. Если запрошена только расцветка, примени перекраску из шага 3.

## Прочитай сначала

1. [pose.json](../../../../DSS-Images/Characters/W8/Antropik/three-quarter-right/pose.json) задаёт размеры холста, область портрета, точку вставки, линию шеи и порядок наложения.
2. [GREEN.uncut.png](../../../../DSS-Images/Characters/W8/Antropik/work/outfit/GREEN.uncut.png) — базовый костюм с цельной шеей и подложка для рисования. [Клиентский GREEN.png](../../../src/DeepSpaceSaga.Client/Images/Persons/W8/Clothes/ThreeQuarterOutfit/GREEN.png) — эталон готового тела, из которого создаётся итоговый PNG. У текущей базы на строках y=102–105 левый край шеи при альфе ≥128 проходит через x=120. Это ширина исходного MT6Q2R. При повторной сборке пиксели живописи трёх костюмов берутся из `work/imagegen/standing-outfits-redraw/registered/{GREEN,GRAY,IVORY}.png` в координатах игрового холста. Ниже левый край шеи идёт вертикально до передней кромки воротника. На каждой строке y=102–120 первый слева пиксель кожи с альфой маски ≥124 должен быть в x=121 (проверяй в окне x=110–139 по сохранённой skin-mask.png). Переноси её с актуального GREEN вместе со сглаженным краем и переходом под воротник.
3. [fabric-mask.png](../../../../DSS-Images/Characters/W8/Antropik/work/outfit/fabric-mask.png) и [skin-mask.png](../../../../DSS-Images/Characters/W8/Antropik/work/outfit/skin-mask.png) задают редактируемую ткань и защищённую кожу. Используй их альфа-каналы в координатах тела.
4. [Промпт для портретов](ThreeQuarterCharacterCodexPrompt.md) описывает общий атлас, а [контракт skinTone](ThreeQuarterCharacterSkinTone.md) — коррекцию открытой кожи.

Рабочая папка — `D:/DeepSpaceSaga/DSS-Images/Characters/W8/Antropik`. Python — `D:/DeepSpaceSaga/DSS-Images/tools/modular-character-pilot/.venv/Scripts/python.exe`.

Каталог готовых костюмов — `D:/DeepSpaceSaga/DSS/src/DeepSpaceSaga.Client/Images/Persons/W8/Clothes/ThreeQuarterOutfit`.

## Шаг 1. Зафиксируй базу и области правки

1. Перечитай GREEN и зафиксируй контрольные суммы базового PNG, подложки, масок, направляющих и существующих костюмов. Сохрани исходное состояние `pose.json` для сравнения полей. Используй снимки и промежуточные файлы только в `D:/DeepSpaceSaga/artifacts/validation/<task>/<run>/`.
2. Построй прямоугольник портрета `R` из `drawOrigin` и `cellSize`. В текущей позе это x 69–212, y 0–189 включительно на холсте 282 × 747. В этой области лежит стык шеи и перекрытие плеч волосами.
3. Вычисли допустимую ткань `F = (baseAlpha == 255) ∧ (fabricMaskAlpha > 0) ∧ (skinMaskAlpha == 0)`. Для нового рисунка разрешённая область `E = F ∧ ¬R`. При необходимости сузь её до нужных панелей одежды. Для перекраски используй только `F`.
4. Поза, геометрия выреза, ворот у шеи, линия стыка с портретом и альфа тела сохраняются из GREEN. Существующие портреты, их настройки и остальную геометрию манифеста сохрани побайтно или, для `pose.json`, по значениям полей.

## Шаг 2. Подготовь рисунок одежды

Для нового рисунка передай ImageGen базовую подложку `GREEN.uncut.png`. Если увеличиваешь её для инструмента, используй целочисленный NEAREST от полного холста. Рабочую маску передай отдельным референсом, если это поддерживается, и всё равно примени её при экспорте. Для одной расцветки этот шаг пропусти.

```text
Edit the supplied DSS W8 three-quarter-right coverall in place.
Costume design: <materials, colours and details>.
The source fixes the entire canvas, pose, body proportions, shoulders,
neck opening, collar contour, hand and boot positions, and silhouette.
Keep the original framing and alignment. Use the allowed cloth panels
for the design. Keep the upper portrait and neck docking area as supplied.
Maintain the base light direction and matte painted materials.
Keep details inside the original body silhouette.
```

Приведи рисунок к холсту базы в тех же координатах. Сверь положение плеч, локтей, пояса, коленей и стоп. Если изменилось кадрирование или ключевые ориентиры сместились, переделай рисунок. Геометрия и альфа итогового тела берутся непосредственно из готового GREEN.

## Шаг 3. Собери итоговый PNG из точной копии GREEN

1. Начни с копии клиентского `W8/Clothes/ThreeQuarterOutfit/GREEN.png`. Для нового рисунка перенеси только RGB из разрешённой области `E`. Для плавного перехода по краям используй вес маски ткани, обнулённый за пределами `E`. В зоне портрета `R` остаётся исходный RGBA.
2. Для заказанной перекраски вычисли RGB из исходных пикселей GREEN, сохраняя объём и тени. Применяй цвет по маске `F`, в том числе на её непрозрачной ткани внутри `R`, если это нужно для единой расцветки. Геометрия воротника сохраняется, а кожа, прозрачность и сглаженные края остаются исходными. Для серого цвета возьми за основу `gray_variant` в `tools/build_pilot.py` и примени разрешённую маску.
3. Сохрани кандидата как RGBA8 sRGB со straight alpha и исходным размером холста. Сохрани шею целиком от воротника до верхней кромки вместе с цветом кожи и сглаживанием GREEN. Линию neckSeam использует только компоновщик при наложении портрета.

Фиксация сглаженного края важна для задних прядей. В существующих атласах `visible_back_hair` уже учитывает перекрытие базовым телом и смешивание на его полупрозрачных краях. Сохранение альфы и RGBA этих краёв гарантирует совместимость с теми же атласами.

## Шаг 4. Проверки перед добавлением

Перечитай сохранённый PNG и сравни с исходным GREEN по координатам пикселей.

| Проверка | Условие выпуска |
|---|---|
| Формат и контур | Режим RGBA8, размер из `pose.json`, альфа совпадает пиксель в пиксель по всему холсту |
| Кожа и шов | RGBA во всех пикселях маски кожи совпадает. От верхней кромки шеи до воротника цвет и альфа совпадают с цельным GREEN, включая пиксели выше линии стыка |
| Сглаженные края | RGBA каждого пикселя GREEN с альфой от 1 до 254 совпадает |
| Область портрета | Для нового рисунка все RGBA в `R` совпадают. Для перекраски изменения в `R` совпадают с расчётной перекраской GREEN по `F` |
| Разрешённая область | Все изменённые RGB находятся в `E` для нового рисунка или `F` для перекраски. За пределами разрешённой области RGBA совпадает |

Проверь точное равенство массивов. В отчёте об ошибке укажи первую координату, число отличающихся пикселей и ожидаемый слой. Если проверка выявила изменение защищённой области, восстанови её из GREEN и повтори проверку сохранённого файла.

В изолированной копии конфигурации добавь путь временного кандидата в `outfits` и укажи в `portraitAtlas` абсолютный шаблон до клиентского `W8/Portraits/{id}/threequarter.png`. Скопируй в конфигурацию направляющую по пути `neckSeam.bodyGuide` и сохрани `neckSeam.bodyHasFullNeck = true`. Запусти `tools/dss3q.py validate --pose <временная папка позы> --outfit <ID> --character 73R83G`. Эта команда сверяет верх шеи с направляющей и проверяет непрозрачность строки стыка. Сравнения из таблицы отдельно гарантируют соответствие базовому костюму.

Осмотри сам костюм в масштабе 1:1. Попиксельные условия выше покрывают совместимость с портретами всех эмоций, поэтому ручная примерка каждой головы при выпуске костюма не требуется. Если дизайн нуждается в новом контуре, другом вырезе или сдвиге точки шеи, он выходит за контракт совместимого костюма W8.

## Шаг 5. Экспорт

1. Сохрани проверенный цельный костюм в `work/outfit/<ID>.uncut.png`. Скопируй этот же файл под именем `<ID>.png` в клиентский каталог `Images/Persons/W8/Clothes/ThreeQuarterOutfit` и добавь ключ `<ID>` со значением `Clothes/ThreeQuarterOutfit/<ID>.png` в `pose.json → outfits`. Рабочий компоновщик разрешает этот путь относительно клиентского W8. Маска открытой кожи остаётся общей для совместимых костюмов.
2. Проверь равенство SHA-256 рабочего и клиентского PNG, проверь контрольные суммы эталонов и убедись, что в `pose.json` добавилась только новая запись костюма. Сверь, что `Pose.outfit_path(<ID>)` указывает на клиентский PNG.
3. Удали временные проверочные файлы текущего запуска. В чат дай короткий ответ с путём к PNG и результатом проверок. Проверочные картинки в ответ не прикладывай. Коммит выполняй только по запросу.
