# W8 · Тон кожи и сборка модульного персонажа

Этот контракт используют при примерке сохранённых PNG и при реализации рендера. [Инструкция по производству портретов](ThreeQuarterCharacterCodexPrompt.md) определяет комплект персонажа и проверки рисунка.

## Данные и порядок слоёв

В `Images/Persons/W8/Portraits/<id>/settings.json` хранится один полутон собственной кожи персонажа для обеих поз, всех эмоций и костюмов. Формат — sRGB, шесть шестнадцатеричных цифр.

```json
{ "skinTone": "#C27D5A" }
```

Используй заданный тон или возьми медиану небольшого участка освещённой щеки принятого нейтрального лица. Исключи блик, глубокую тень, губы, румянец и волосы. Сохрани рисунок лица в его собственных цветах. Если настройка отсутствует или некорректна, используй базовый тон **выбранной позы**.

| Поза | Тело относительно `W8/Clothes` | Портрет | Открытая кожа тела |
|---|---|---|---|
| Три четверти | `ThreeQuarterOutfit/<ID>.png` | `threequarter.png` | Базовый тон `#DA9C77`. Источник маски GREEN и GRAY — [skin-mask.png](../../../../DSS-Images/Characters/W8/Antropik/work/outfit/skin-mask.png). |
| Пленный | `Prisoner/<ID>.png` | `prisoner.png` | Возьми `referenceSkinTone` и `masks.skinByOutfit[ID]` из [шаблона позы](../../../src/DeepSpaceSaga.Client/Images/Persons/W8/Clothes/Prisoner/Templates/pose.json). Пути разрешаются относительно шаблона. |

По манифесту позы выбери тело, прямоугольник эмоции и точку вставки. Нарисуй тело, затем ячейку портрета в натуральном размере оператором source-over. Для стойки с `bodyHasFullNeck=true` перед наложением ячейки обнули в теле пиксели выше `firstBodyPixelYByColumn` **только** в столбцах `startX..endXInclusive`. Саму строку шва оставь телу. Верх общей шеи уже включён в атлас. Отдельно стоящий костюм показывай целиком. Для пленного рисуй полное тело и голову поверх него. Кожа до кадыка нарисована в собственном цвете головы.

## Цвет тела

Вычисляй поканально в числах sRGB с плавающей точкой. `base` и `skinTone` должны быть в одной шкале. Для straight RGBA8:

```text
gain = skinTone / base
outRGB = round(clamp(inRGB * (1 + mask * (gain - 1)), 0, 255))
outAlpha = inAlpha
```

- **Стойка.** Вес открытой кожи — `min(alphaSkin / 248, 1)`. Обнули его на прозрачном фоне и в зоне [fabric-mask.png](../../../../DSS-Images/Characters/W8/Antropik/work/outfit/fabric-mask.png). Для IVORY отдельная стоящая маска в комплекте отсутствует. На примерке используй общую маску там, где RGBA тела совпадает с GREEN. Остальные участки сохраняют исходный цвет до подготовки собственной маски IVORY.
- **Пленный.** Одноканальная маска соответствующего костюма даёт вес `L / 255`. Запасная `masks.skin` подходит для подтверждённой геометрии кожи GREEN. Если подходящей маски нет, сохрани исходный цвет тела и отметь ограничение при проверке.
- Множитель сохраняет тени и блики. При работе с premultiplied RGB сохраняй альфу и ограничивай результат допустимым для неё диапазоном. Волосы, ткань и нарисованное лицо сохраняют исходный RGB.

## Верх общей шеи в стойке

В каждой ячейке стойки голова и часть общей шеи уже сведены. Чтобы точно окрасить видимую кожу под полупрозрачными волосами и краем челюсти, вычисли её вклад из исходных слоёв этой эмоции. Используй вырезанную по шву шею импортёра и покрытие головы из `build_pilot.head_layers`, включая видимую часть задних волос. Все альфа-величины ниже нормализованы в 0…1.

```text
neckContribution = neckRGB * neckAlpha * (1 - headAlpha) * mask
outPremulRGB = atlasRGB * atlasAlpha + neckContribution * (gain - 1)
```

Для straight RGBA8 при ненулевой альфе раздели результат на `atlasAlpha`, затем ограничь диапазон и округли. При нулевой альфе оставь пиксель прозрачным. Применение `gain` ко всей ячейке повторно окрасит лицо. Для `prisoner.png` коррекция цвета ячейки не требуется.

**Граница игровой интеграции.** Рабочие слои позволяют точно вычислить вклад шеи при производственной примерке. Клиентский комплект персонажа состоит из двух атласов и JSON. Для точного тонирования стойки в рантайме рендеру понадобится эквивалентный доступ к маске тела и вкладу шеи. Их можно подготовить при сборке ресурсов. При отсутствии вклада верхней шеи отмечай, что проверена только коррекция тела. При кэшировании учитывай позу, костюм, персонажа и тон для соответствующего слоя. Смена эмоции выбирает ячейку готового атласа.

**Проверка.** При `skinTone == base` результат совпадает с базовой сборкой. При другом тоне альфа остаётся исходной, видимые пиксели вне кожи сохраняют цвет. При 1:1 и ×4 осмотри обе стороны шеи, переход из-под подбородка в вырез, волосы и ворот каждого костюма. Проверка сборки по PNG и проверка в работающем клиенте — разные результаты.
