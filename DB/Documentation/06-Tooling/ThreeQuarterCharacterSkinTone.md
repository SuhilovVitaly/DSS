# Сборка персонажа W8 с skinTone

В каждой папке `Images/Persons/W8/Portraits/<id>/` проекта `DeepSpaceSaga.Client` лежат `threequarter.png` и `settings.json`. Имя папки — ID персонажа в нижнем регистре. Поле `skinTone` задаёт эталонный полутон открытой кожи персонажа в формате sRGB `#RRGGBB`. Оно общее для всех эмоций и костюмов.

```json
{
  "skinTone": "#B16B43"
}
```

Это значение W8A036. Остальные значения подобраны по полутонам щёк в ячейке `neutral`. Их можно уточнять по сборке без перерисовки атласа.

## Загрузка и порядок отрисовки

1. Выберите позу, затем костюм из её каталога в `Images/Persons/W8/Clothes/`. Для стойки в три четверти используйте `ThreeQuarterOutfit/` с костюмами `GRAY`, `GREEN` и `IVORY`. Папка `Prisoner/` подготовлена для будущей позы. Для сборки используйте атлас, совместимый с выбранной позой. Загрузите тело и его маску открытой кожи в координатах холста. Для стойки в три четверти размеры, положение ячейки, порядок эмоций и порядок отрисовки берите из [pose.json](../../../../DSS-Images/Characters/W8/Antropik/three-quarter-right/pose.json). Для GREEN и GRAY используется одна геометрия маски.
2. Прочитайте `skinTone` из `Images/Persons/W8/Portraits/<id>/settings.json`. При отсутствии файла, поля или корректного цвета используйте `#DA9C77`, исходный полутон тела. Если маска недоступна, отрисуйте исходное тело.
3. Примените коррекцию к телу и к открытой коже верхней шеи в выбранной ячейке портрета. Отрисуйте тело, затем портрет. Для текущего контракта это тело 282 × 747 и ячейка 144 × 190 в точке (69, 0). Порядок ячеек слева направо — `neutral`, `pain`, `anger`, `joy`, `pleasure`.
4. Перекрашивайте тело при загрузке персонажа или при смене костюма. Кэшируйте по пути тела с учётом позы и значению `skinTone`. Пять ячеек портрета можно скорректировать при загрузке атласа и кэшировать по идентификатору атласа и тону. Смена эмоции выбирает готовую ячейку.

## Коррекция цвета

Для совпадения с примеркой W8A036 вычисляйте поканальное отношение `gain = skinTone / #DA9C77` в числовых значениях sRGB. Маска `m` принимает значения от 0 до 1. Для тела используйте `rgbOut = clamp(rgbIn * (1 + m * (gain - 1)))`. Альфа остаётся исходной. Такой множитель сохраняет рисунок освещения. При расчёте на premultiplied текстуре умножайте RGB по той же формуле, сохраняя альфу.

Рабочий источник маски для GREEN и GRAY — [skin-mask.png](../../../../DSS-Images/Characters/W8/Antropik/work/outfit/skin-mask.png). При подготовке игровой маски берите её альфа-канал, нормализуйте как `min(alpha / 248, 1)` и обнуляйте маску на прозрачных пикселях экспортированного тела и в зоне [fabric-mask.png](../../../../DSS-Images/Characters/W8/Antropik/work/outfit/fabric-mask.png). Упакуйте маску вместе с игровым ассетом тела в тех же размерах и координатах. В маску входят шея и кожа в вырезе. Ткань, молния и воротник получают вес 0.

### Стык с атласом

В существующих атласах верхняя часть общей шеи уже сведена с головой. Поэтому для точной перекраски обеих сторон стыка нужен дополнительный экспорт из слоёв для каждой из пяти ячеек. Экспортируйте видимый вклад **общей кожи шеи** в premultiplied RGB после перекрытия головой и волосами. Умножьте этот вклад на вес маски кожи при экспорте. Лицо, окрашенная часть портрета и волосы дают нулевой вклад в эту текстуру.

В рендере добавьте к premultiplied RGB пикселя атласа `neckContribution * (gain - 1)` и сохраните исходную альфу. Фон, лицо, волосы и полупрозрачные пересечения сохранят свой вклад. Для straight RGBA после коррекции разделите RGB на альфу в ненулевых пикселях. При базовом тоне коэффициент равен 1 и кадр должен совпасть с исходной сборкой.

Сейчас каталог содержит настройки и исходные атласы. Для игровой интеграции предстоит добавить загрузку настроек и экспорт масок тела и вклада верхней шеи. При отсутствии данных верхней шеи применима коррекция тела, а верхнюю кромку нужно проверить в сборке перед выпуском. Для проверки используйте W8A036 на GREEN и GRAY во всех пяти эмоциях. Пиксели за пределами кожи и альфа должны совпадать с базовой сборкой.
