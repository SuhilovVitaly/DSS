# Загрузка игры

> **Контракт EP-0013.** EP-0013: после saved tuning bootstrap применяет валидный debug-tuning.json обычной командой, включая retiming восстановленных снарядов; отсутствующие ключи частичного файла берутся из каталога. Invalid файл отвергается целиком. Перед чтением файла заменяющей сессией предыдущий writer завершается; Load сбрасывает физический ввод. [Текущий контракт](../../04-Engineering/DebugTuningPanel.md#файлы-и-продолжение).

Показывает слоты, запускает новую локальную сессию только после проверки файла. Load начинает на паузе, восстанавливает materialized состояние и прекращает старые клиентские worker/observation histories. При ошибке файл не переписывается. Save18 мигрируется, остальные старые версии не обещаются совместимыми.

См. [каталог экранов](ScreenCatalog.md) и [основные требования](../../01-Requirements/EngineRequirements.md).

Слоты берутся из AppPaths.Current.Saves; перенос старых слотов не меняет
формат Save19/18. [Текущий persistence контракт](../../04-Engineering/SaveFormat.md).
