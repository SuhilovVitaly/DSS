# Диалог

Общий DialogueScreen показывает говорящего, роль, текст и варианты ответа. Engine владеет dialogue state, условиями и эффектами. Смена реплики не должна менять личность персонажа; портрет собирается из W4/M4 в памяти.

См. [каталог экранов](ScreenCatalog.md) и [основные требования](../../01-Requirements/EngineRequirements.md).

Источники: [DialogueScreen.cs](../../../../src/DeepSpaceSaga.Client/UI/Screens/Dialogue/DialogueScreen.cs).

Пиратская sensor-сводка замораживает подтверждённые типы носителей, одну приблизительную численность и ETA. Несколько новых групп одного шага объединяются в одну сводку и одну паузу. Ирина использует свой портрет; резервный скрипт — без портрета. Закрытие подтверждает batch, но оставляет Speed0; повторное обнаружение той же группы автоматически диалог не открывает. См. [DemoEncounters](../Mechanics/DemoEncounters.md).
