# Результаты боя

После любого завершённого боя кнопка «Результаты боя» открывает обязательное модальное окно. В сводке видны исход, ходы, выстрелы, попадания и потери сторон. Для собственного вылета показан подтверждённый расход торпед. После явного выхода с погибшим носителем открывается штатный экран гибели.

Рамка совпадает с окном станции. Карточки вражеских дронов и носителей раскрываются независимо. Строки под карточкой занимают доступную ширину прокручиваемого списка. Футер остаётся на месте и показывает свободный трюм и исправные свободные каюты живого носителя.

После победы с правом на добычу окно последовательно показывает «Арест пилотов», «Модули и расходники» и «Разбор на металлолом». Шаг ареста показывается, только если есть живой пилот, которого можно арестовать. После заполнения последней свободной каюты арест остальных пилотов недоступен. Модули и расходники доступны у отключённых дронов. «Забрать всё» запускает только операции текущего шага и раскрывает их карточки. Полосы заполняются снизу вверх, включая операции за пределами видимой части списка. Пока операция или подтверждение записи ожидает завершения, переход дальше закрыт.

«На карту» доступна на шаге металлолома после завершения операций и подтверждения записи. В бою без права на добычу выход доступен из сводки. При остатках окно показывает оставляемое имущество и живых неарестованных пилотов. «Остаться» возвращает список без изменений. «Уйти на карту» окончательно закрывает сбор. F5/F9 доступны в стабильном окне результатов с обычными ограничениями быстрых слотов. При загрузке результаты открываются на первом подходящем шаге с сохранёнными арестами и добычей. Повтор после сбоя записи использует тот же результат.
