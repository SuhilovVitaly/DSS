# Сохранение игры

Экран сохраняет мир в именованный слот через сессию. F5 записывает быстрый слот, F9 загружает его на паузе. Правила слотов, миграции и ошибок — в [SaveFormat](../../04-Engineering/SaveFormat.md).

В активном [тактическом бою](TacticalBattle.md) запись и загрузка недоступны. В [результатах боя](BattleResults.md) быстрые слоты доступны в стабильном состоянии. Сохранение запоминает позу и скорость корабля без физического удержания клавиш.

Источник: [SaveScreen](../../../../src/DeepSpaceSaga.Client/UI/Screens/Save/SaveScreen.cs).

У встречи отдельно записываются durable pending до старта и finished после исхода.
Это checkpoint целого мира и перезапуск боя, не сохранение его текущего хода.
Ошибка finished write удерживает итог; повтор записи не повторяет settlement.

## Сохранение результатов боя

Слот хранит подтверждённый итог, стадию окна и существующий ledger добычи. Временные операции существуют в runtime до завершения. Повтор неудавшейся записи продолжает checkpoint с уже применённым результатом. [Контракт](../../04-Engineering/DemoRewards.md).
