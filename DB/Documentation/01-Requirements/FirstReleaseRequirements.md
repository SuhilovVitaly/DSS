# Границы текущей игры и первого релиза

> **Контракт EP-0013.** EP-0013 добавляет доступную во всех сборках F12-панель и независимые WASD/стрелки с защёлкой Shift. Нормативные границы: [панель](../04-Engineering/DebugTuningPanel.md), [маневрирование](../04-Engineering/ManualManeuver.md). UI, файлы, Save19/18 и ручной ввод относятся к реализованным контрактам; human/audio/physical-input приёмка не выводится из этого статуса.

Основные игровые контракты заданы в [EngineRequirements](EngineRequirements.md).
Цикл игры: выбрать сценарий → управлять кораблём и модулями → обследовать объекты,
лететь к станции, стыковаться, торговать и продолжать рейс; в бою запускать
торпеды/контрмеры, маневрировать и читать доклады. Сохранение продолжает
материализованный мир, экономику и боевые deadlines.

| Область | Граница реализации |
|---|---|
| Управление | Тактическая карта, выбор/hover, команды модулей, орбита, Approach, пауза/скорости |
| Мир | Seeded система, орбиты, станционные кластеры, ресурсные поля, базы ИИ, POI |
| Экономика | Trade quotes/receipts, конечные рынки, Fuel, cargo cost, finance/voyage ledger |
| Бой | Точечные пуски/взрывы, ручная защита, уклонение, урон модулей, Defeat, reports |
| Persistence | Save19, миграция Save18, слоты и продолжение состояния |
| Диалоги/лица | Общий DialogueScreen и композиция W4/M4 |
| Hire / Contracts / Ship | Экраны-оболочки; полноценные системы найма, пассажирских контрактов и обзора корабля не завершены |
| DebugTuning | F12-панель, файлы и независимые ручные оси реализованы; human/physical/audio приёмка остаётся открытой |
| Поля и POI | Информация/геометрия; не обещают воздействие среды, исследования и награды |

Не считать подготовленные карточки реализацией, успешные unit tests — приёмкой
интерфейса, а наличие balance tool — доказательством игрового баланса.
Детали текущих экранов: [ScreenCatalog](../02-FirstRelease/Screens/ScreenCatalog.md).
Планы, порядок и фактическая приёмка хранятся только в [Board](../../Board).
