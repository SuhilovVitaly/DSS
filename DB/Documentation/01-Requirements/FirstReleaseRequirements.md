# Границы текущей игры и первого релиза

Основные игровые контракты заданы в [EngineRequirements](EngineRequirements.md).
Игрок управляет кораблём и модулями, обследует объекты, летит к станциям, торгует и продолжает рейс. С карты доступен отдельный [тактический бой](../02-FirstRelease/Screens/TacticalBattle.md) носителей и дронов. Сохранение продолжает материализованный мир и экономику.

| Область | Граница реализации |
|---|---|
| Управление | Тактическая карта, выбор/hover, команды модулей, орбита, Approach, пауза/скорости |
| Мир | Seeded v2 география с frozen опорной скоростью, орбиты, станционные кластеры, ресурсные поля, базы ИИ, POI; v1 Load без переразмещения |
| Экономика | Trade quotes/receipts, конечные рынки, Fuel, cargo cost, finance/voyage ledger |
| Бой | Отдельная временная сессия: движение, выбор целей, последовательная стрельба по инициативе, сознание и уклонение, карточки/панель фазы и итог; журнал сохраняется в данных |
| Сохранение | Save20, чтение и миграция Save18/19, слоты мира |
| Диалоги/лица | Общий DialogueScreen и композиция W4/M4 |
| Hire / Contracts / Ship | Экраны-оболочки; полноценные системы найма, пассажирских контрактов и обзора корабля не завершены |
| DebugTuning | F12, параметры двух типов двигателей, файлы настройки и независимые ручные оси |
| Поля и POI | Информация/геометрия; не обещают воздействие среды, исследования и награды |

Не считать подготовленные карточки реализацией, успешные unit tests — приёмкой
интерфейса, а наличие balance tool — доказательством игрового баланса.
Детали текущих экранов: [ScreenCatalog](../02-FirstRelease/Screens/ScreenCatalog.md).
Планы, порядок и фактическая приёмка хранятся только в [Board](../../Board).
