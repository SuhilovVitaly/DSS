   name/captain/tokens and has **no** inline hullLayout/modules/crew/carrierState; any inline

   manifest reference rejects (no file path). Saves never resolve or re-grant; Save21 stores
   expanded state.

   expanded ship. `LoadNeverReappliesManifest` = save round-trip keeps fired ammo/cargo losses.

   55/53/59/50; tactical names/skills stay in `pilots.json` + `tactical-battle-pilots.json`.
   Roles Captain/Officer/Pilot; Dunkan portrait null (default-male fallback), Irina and pilots use
