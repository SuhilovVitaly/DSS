## 1. Контекст и цель

Необходимо исправить и улучшить client-side отображение информации о космических объектах на tactical map. Индикатор внутри label-панели должен остаться квадратом 8x8 px, но вместо плавной смены цвета должен мигать через отрисовку/неотрисовку: 1 секунду квадрат рисуется, 1 секунду не рисуется. Соединительная линия от точки/маркера космического объекта должна приходить точно в ближайший угол панели с названием и индикатором.

### 2.4. Открытые вопросы и допущения

- Допущение: период мигания равен 2000 ms: первые 1000 ms квадрат виден, следующие 1000 ms не рисуется, затем цикл повторяется.
- Допущение: при `SimulationSpeed.Speed0` индикатор не должен продолжать мигать; он остается видимым, как текущая paused-логика возвращала стабильный цвет. Если продуктово требуется blink от wall-clock даже на паузе, нужен отдельный вопрос оператору перед реализацией.
- Допущение: "ближайший угол панели" означает ближайший из четырех углов `PlaqueRect` к screen point объекта по евклидовому расстоянию после viewport clamp-а панели.

## 4. Единицы работы для Phase 3

### 4.1. Обновить модель мигания status square

- Цель: заменить цветовой blending на бинарную видимость квадрата.
- Вход: `StatusSquareAnimator.cs`, `ObjectLabelRenderer.cs`, `ObjectLabelTests.cs`.
- Изменения:
  - Заменить смысл helper-а с "вернуть измененный цвет" на "определить, должен ли квадрат рисоваться в текущую фазу".
  - Закрепить период 2000 ms и фазу on/off по 1000 ms.
  - При видимой фазе рисовать исходный `objectColor` без brightness shift.
  - При невидимой фазе не вызывать `canvas.DrawRect` для `geometry.StatusRect`.
  - При `SimulationSpeed.Speed0` сохранить стабильное поведение: квадрат виден исходным цветом, без мигания.
- Выход: indicator остается 8x8 px, но визуально мигает через наличие/отсутствие.
- Проверка:
  - Unit-тесты на `0 ms`, `999 ms` -> виден.
  - Unit-тесты на `1000 ms`, `1999 ms` -> не виден.

## 6. Trade-offs и альтернативы

- Альтернатива "делать off-фазу через прозрачный цвет" отклонена: пользователь явно сформулировал "секунду квадрат рисуется, потом секунду нет".
- Альтернатива "оставить smoothstep и добавить alpha fade" отклонена: новая стратегия бинарная, без замены другим цветом.
- Альтернатива "вести линию к ближайшей стороне панели" отклонена: требуется ближайший угол панели.
- Выбранный путь минимален: изменение ограничивается helper-а логики видимости, renderer branch и geometry endpoint.
