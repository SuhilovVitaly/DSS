# Пушки (`Modules/Weapons/`)

Модуль пушки: на дрон ставится ровно одна, у носителя пушки нет. Пушка стреляет один раз за ход в фазе стрельбы по цели внутри своего сектора (Spec/Combat.md §6).

| Поле | Смысл |
|---|---|
| `name`, `tier` | название, уровень снаряжения (на механику не влияет) |
| `arcDeg` | **полусектор**, °: цель в секторе, если \|угол от носа\| ≤ `arcDeg`. Полный угол — 2 × `arcDeg` |
| `range` | дальность: цель в секторе, если расстояние ≤ `range` |
| `damageMin`, `damageMax` | урон попадания — целое, равномерно от min до max включительно |
| `piercing` | очков урона идут в корпус мимо брони (целое ≥ 0) |
| `hitBonus` | прибавка к шансу, п.п., целое |
| `rangeBonus` | необязательно: бонус за близость в упор, п.п. Если поля нет — `rules.hit.rangeBonus` (прочерк в таблице) |
| `rearKillChance` | шанс мгновенной гибели цели при попадании в корму, 0…1 |
| `massKg` | масса, кг |

Пушки 1-го уровня — оружие «Начального боя»:
- копьё I — точное и дальнобойное;
- меч I — уронный;
- самопал I и обрез I — оружие тагов: у них нет мгновенной гибели в корму.

Пушки 2-го уровня в сценарии не используются: их числа переведены в масштаб урона V4, баланс на них не проверялся.
