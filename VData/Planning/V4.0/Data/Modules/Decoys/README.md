# Модули ловушек

`id` — имя файла; `name` — название; `tier` — уровень ≥0; `charges` — целое ≥1; `missFactor` — множитель вероятности промаха ≥1; `massKg` — масса ≥0. Ловушка действует на первый фактический выстрел текущего залпа; заряд тратится при фиксации приказа.
