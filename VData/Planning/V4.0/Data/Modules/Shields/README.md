# Щиты (`Modules/Shields/`)

Щит — это не броневой слой, а маневровые двигатели: он помогает уклоняться и почти ничего не весит. На дрон ставится 0…`shieldSlots` рамы одинаковых щитов: тяжёлому до 2, лёгкому и тагу до 1. Число задаёт `shieldCount` компоновки.

- Защита и масса щитов складываются.
- Защита вычитается из шанса попадания по владельцу (п.п.) при любом выстреле, кроме выстрела в корму (Spec/Combat.md §6.2–6.3).
- Щит не изнашивается и не ломается.

| Поле | Смысл |
|---|---|
| `name`, `tier` | название, уровень снаряжения |
| `defense` | минус к шансу попадания по владельцу за один щит, п.п., целое ≥ 0 |
| `massKg` | масса одного щита, кг |
