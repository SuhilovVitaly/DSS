# Бронеплиты (`Modules/Armor/`)

Модуль брони: на дрон ставится ровно один, без брони — `armor.none`. Броня — целый пул очков (Spec/Combat.md §6.4):
- попадание сначала тратит броню, остаток идёт в корпус;
- `piercing` пушки идёт в корпус мимо брони;
- в корму броня не защищает.

Броня не восстанавливается.

| Поле | Смысл |
|---|---|
| `name`, `tier` | название, уровень снаряжения |
| `armor` | очков брони, целое ≥ 0 |
| `massKg` | масса, кг |

Таги носят обшивку из хлама, латаные и лёгкие плиты (20–50): оружие игрока снимает такую броню за 1–1.5 попадания. Дроны игрока — средние плиты (80): оружие тагов снимает их за 2–2.5 попадания.
