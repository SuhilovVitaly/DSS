# Рамы (`Frames/`)

Рама — класс корпуса. На неё монтируются модули (Data/README.md): пушка, бронеплиты, щиты и двигатели в пределах слотов рамы. Рама `carrier` — носитель: без модулей, неподвижен, пилота нет.

| Поле | Смысл |
|---|---|
| `name` | название |
| `hull` | корпус, целое > 0. Компоновка может задать свой `hull` |
| `frameMassKg` | масса рамы, кг |
| `referenceMassKg` | эталонная масса: вклад двигателей умножается на эталон / массу дрона (Spec/Combat.md §3) |
| `minSpeed` | минимальная скорость = vmin |
| `maxSpeedCap` | потолок vmax |
| `turnCapDeg` | потолок поворота за ход, ° |
| `engineSlots` | сколько двигателей можно поставить |
| `shieldSlots` | сколько щитов можно поставить; по умолчанию 1 |
| `maneuver` | только у `carrier`: его «манёвренность» в формуле шанса, целое |

Рама `carrier` обязательна. У неё только `name`, `hull`, `maneuver`; прочерк в таблице — поля нет.
