# Стиль тактических кнопок

Спокойная приборная панель: тёмная синяя поверхность, тонкая рамка, простая
крупная пиктограмма. Без фасок, винтов, glow, потёртостей и декоративных подписей.
Главный критерий — читаемость при 48×48.

| Элемент | Цвет |
|---|---|
| Внешнее поле / поверхность | #09121B / #0D1C28 |
| Рамка / основной символ | #2B4456 / #E6EFF5 |
| Второстепенный / hover | #93ADBE / #32C6E0 |
| Hover surface / подтверждение | #113849 / #F5B141 |
| Успех / ошибка | #77D0A0 / #F29286 |

commands-panel: PNG 64×64, отображение 48×48; `.active.png` означает hover,
а не выполняемую команду. Navigation-panel сохраняет размер 128×130;
title-bar — 26×26. Одинаковая команда использует согласованный символ.
Янтарный — подтверждение важного действия, не универсальный цвет карты.
Численные runtime palette overrides берутся из content и не меняют этот
авторский контракт подготовки новых пиктограмм автоматически.

Источники: [Export-TacticalButtonAssets.ps1](../../../../tools/Export-TacticalButtonAssets.ps1).
