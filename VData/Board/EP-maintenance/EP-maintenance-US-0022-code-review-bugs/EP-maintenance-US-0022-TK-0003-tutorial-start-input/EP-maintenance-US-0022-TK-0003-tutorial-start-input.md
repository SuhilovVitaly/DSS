# Ввод в главном меню во время запуска обучения

[История](../EP-maintenance-US-0022-code-review-bugs.md)

## Ожидаемый результат

Пока запускается обучение, главное меню не принимает повторные команды, а «Выход» выполняется. После открытия боя не появляется плашка «действия мира заблокированы» из-за кликов, сделанных до старта.

## Why

Найдено код-ревью 2026-11-15 на main `113b8506`. Источник: EP-0027-US-0001-TK-0001. Серьёзность: minor. Уверенность: CONFIRMED.

**Дефект.** `StartTutorialAsync` держит `_transitionLock` через несколько await (создание мира, SetSpeed, StartAsync), а главное меню остаётся интерактивным. События из очереди обрабатываются уже после открытия боя, шлюз боя их отклоняет и вызывает `NotifyWorldActionBlocked()`.

**Сценарий.** Двойной щелчок по «Новой игре» открывает обучение с красной плашкой на 4 с. Щелчок «Выход», «Настройки» или «Загрузить» во время загрузки молча теряется, игрок попадает в обучение вместо выхода. До EP-0027 «Новая игра» открывала выбор сценария синхронно.
